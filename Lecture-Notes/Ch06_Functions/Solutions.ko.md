## 연습 문제 1: 실수 반올림

**문제:** 실수를 전달받아 소수 첫째 자리에서 반올림한 정수를 반환하는 함수를 정의하고, 이 함수로 `0.0`이 입력될 때까지 실수를 읽어 반올림 결과를 출력하라. 양수와 음수 모두 올바르게 반올림해야 한다. 문제 전문과 실행 예시는 [연습 문제 1](Exercises.ko.md#연습-문제-1-실수-반올림)에 있다.

### 풀이

**접근 방법:** `double` 값을 `(int)`로 형 변환하면 소수 부분을 버리고 0 쪽으로 자른다. 따라서 양수는 0.5를 더한 뒤, 음수는 0.5를 뺀 뒤 자르면 소수 첫째 자리에서 반올림한 결과가 된다.

- **`round_value()`:** `value`가 양수이면 0.5를 더하고, 그렇지 않으면 0.5를 뺀 다음 `(int)`로 변환하여 반환한다. 2.75는 3.25가 되어 3, 9.1은 9.6이 되어 9, -6.3은 -6.8이 되어 -6, -7.815는 -8.315가 되어 -8이 된다. `value`가 0이면 0.5를 빼는 쪽으로 처리되어 -0.5가 되지만, 0 쪽으로 잘리므로 0이 된다.
- **함수 이름:** 풀이 코드는 함수 이름을 `round_value()`로 지었다. `round`는 C99부터 `<math.h>`에 `double round(double)`로 선언된 표준 라이브러리 함수의 이름이어서, 문제의 이름 그대로 `int round(double)`을 정의하면 `<math.h>`를 포함하지 않아도 gcc는 내장 함수와 타입이 충돌한다는 경고(`conflicting types for built-in function 'round'`)를, clang은 라이브러리 함수를 다르게 다시 선언했다는 경고를 낸다.
- **`main()`:** `do { ... } while (1);`의 무한 반복 안에서 실수를 `%lf`로 읽고, 0.0이면 `break`로 반복을 끝낸다. 그 밖의 값은 `printf`의 `%lf`(출력에서는 `%f`와 같다)로 입력값을 소수 여섯째 자리까지 출력하고, `round_value()`의 반환값을 `%d`로 출력한다. 반환값을 변수에 저장하지 않고 `printf`의 인수로 바로 쓰는 것은 반환값이 있는 함수 호출이 식이기 때문이다([6장 2.5절](Concepts_Lecture.ko.md#25-함수-호출)).

**코드:** [Lab_Q1.c](../../Coursework/Lab06_Functions/Lab_Q1.c)

```c
/**
 * @file    A10104-1_C06Q1.c
 * @brief   Q1. 실수 반올림
 * @author  박철원 (Cheolwon Park)
 * @date    2024-04-16
 * 
 * @note    소스 코드에 사용된 scanf_s는 Visual Studio 이외의
 *          IDE에서 실행이 불가할 수 있음에 주의하시기 바랍니다.
 */

#include <stdio.h>

int round_value(double value)
{
    if (value > 0) {
        value += 0.5;
    }
    else {
        value -= 0.5;
    }
    return (int)value;
}

int main()
{
    double num;
    
    do {
        printf("실수를 입력하세요 (0.0 입력 시 종료) : ");
        scanf_s(" %lf", &num);

        if (num == 0.0)
            break;
        else
            printf("%lf의 반올림 결과 = %d\n\n", num, round_value(num));
    } while (1);

    return 0;
}
```

**실행 결과:** `scanf_s`는 Visual Studio가 제공하는 함수이므로, gcc에서는 `gcc -std=c99 -Wall -Dscanf_s=scanf`로 `scanf`로 바꾸어 컴파일하였다(경고 없음). 실행 예시와 같은 값을 입력하면 같은 결과가 나온다. 다만 코드의 프롬프트는 `종료) : `처럼 콜론 앞에 공백이 있어 실행 예시의 `종료): `와 한 칸 다르고, 실행 예시의 마지막 줄 `Program ended with exit code: 0`은 프로그램의 출력이 아니라 Xcode 콘솔이 덧붙이는 종료 메시지이다.

```text
실수를 입력하세요 (0.0 입력 시 종료) : 2.75
2.750000의 반올림 결과 = 3

실수를 입력하세요 (0.0 입력 시 종료) : 9.1
9.100000의 반올림 결과 = 9

실수를 입력하세요 (0.0 입력 시 종료) : -6.3
-6.300000의 반올림 결과 = -6

실수를 입력하세요 (0.0 입력 시 종료) : -7.815
-7.815000의 반올림 결과 = -8

실수를 입력하세요 (0.0 입력 시 종료) : 0.0
```

> **참고:** **`scanf_s`.** `scanf_s`는 C11 부록 K(경계 검사 인터페이스)에 정의된 선택 기능으로, Visual Studio는 제공하지만 gcc와 clang이 쓰는 glibc와 macOS의 C 라이브러리는 제공하지 않는다. 그래서 그대로 컴파일하면 C99 이후의 암시적 선언 규칙에 따라 오류가 난다. `%d`, `%lf`처럼 숫자를 읽는 변환에서는 `scanf`와 똑같이 쓰지만, `%s`, `%c`로 문자를 읽을 때는 버퍼 크기를 추가 인수로 넘겨야 한다.

> **주의:** 이 방식은 2.5처럼 소수 부분이 정확히 0.5인 값을 0에서 먼 쪽으로 반올림한다(2.5는 3, -2.5는 -3). 또 반올림 결과가 `int`의 범위를 넘는 값(예: 3e10)을 입력하면 `(int)` 변환의 결과가 정의되지 않는다.

## 연습 문제 2: 윤년 판별

**문제:** 연도를 받아 윤년이면 1, 평년이면 0을 반환하는 `isLeapYear()` 함수를 정의하고, 이 함수로 2000년부터 2150년까지의 윤년을 한 줄에 10개씩 공백으로 구분하여 출력하라. 문제 전문과 실행 예시는 [연습 문제 2](Exercises.ko.md#연습-문제-2-윤년-판별)에 있다.

### 풀이

**접근 방법:** 윤년 조건을 문제에 주어진 순서대로 검사한다. 4로 나누어떨어지지 않으면 평년, 4로 나누어떨어지지만 100으로는 나누어떨어지지 않으면 윤년, 100으로 나누어떨어지면 400으로도 나누어떨어질 때만 윤년이다.

- **`isLeapYear()`:** 세 조건을 조건 연산자 `? :`를 겹쳐 한 식으로 쓴다. 바깥 조건 `(year % 4) == 0`이 거짓이면 0이고, 참이면 `(year % 100) == 0`을 검사하여 거짓이면 1, 참이면 `(year % 400) == 0`의 결과에 따라 1 또는 0을 반환한다. 이 식은 [6장 2.5절](Concepts_Lecture.ko.md#25-함수-호출)의 `(year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)`과 같은 값을 낸다.
- **`main()`:** 제목을 출력한 뒤 `input`을 2000부터 2150까지 1씩 늘리며 `isLeapYear(input)`이 1인 연도만 `"%d "`로 출력하고 `count`를 1 늘린다. `count`가 10의 배수가 될 때마다 줄을 바꾸므로 한 줄에 10개씩 출력된다.
- **결과 확인:** 2000은 400으로 나누어떨어지므로 윤년이고, 2100은 100으로 나누어떨어지지만 400으로는 나누어떨어지지 않으므로 평년이다. 2000부터 2148까지 4의 배수는 38개이고 그중 2100을 빼면 윤년은 37개이므로, 10개씩 세 줄과 7개인 마지막 줄이 출력된다.

**코드:** [Lab_Q2.c](../../Coursework/Lab06_Functions/Lab_Q2.c)

```c
/**
 * @file    A10104-1_C06Q2.c
 * @brief   Q2. 윤년 판별
 * @author  박철원 (Cheolwon Park)
 * @date    2024-04-17
 */

#include <stdio.h>

int isLeapYear(int year)
{
    return ((year % 4) == 0) ? ((year % 100) == 0 ? ((year % 400) == 0 ? 1 : 0) : 1) : 0;
}

int main()
{
    int input, count = 0;

    printf("-------------------------------------------------\n");
    printf("               2000~2150년 사이의 윤년\n");
    printf("-------------------------------------------------\n");

    for (input = 2000; input <= 2150; input++) {
        if (isLeapYear(input) == 1) {
            printf("%d ", input);
            count++;
            if (count % 10 == 0)
                printf("\n");
        }
    }

    return 0;
}
```

**실행 결과:** 실행 예시와 같은 윤년 목록이 출력된다. 각 연도 뒤에 공백을 출력하므로 줄마다 끝에 공백이 하나 남고, 마지막 줄은 7개를 출력한 뒤 `count`가 10의 배수가 아니어서 줄바꿈 없이 끝난다.

```text
-------------------------------------------------
               2000~2150년 사이의 윤년
-------------------------------------------------
2000 2004 2008 2012 2016 2020 2024 2028 2032 2036 
2040 2044 2048 2052 2056 2060 2064 2068 2072 2076 
2080 2084 2088 2092 2096 2104 2108 2112 2116 2120 
2124 2128 2132 2136 2140 2144 2148 
```

> **참고:** **반환값의 비교.** `main()`은 `isLeapYear(input) == 1`로 반환값을 비교하지만, `isLeapYear()`가 0 또는 1만 반환하므로 `if (isLeapYear(input))`로 써도 같다. C에서 조건식은 0이면 거짓, 0이 아니면 참으로 처리되기 때문이다.

## 연습 문제 3: 월별 날짜 수 계산

**문제:** 연도와 월을 전달받아 그 달의 날짜 수를 반환하는 `GetDaysOfMonth()` 함수를 정의하고, 입력받은 연도와 월의 날짜 수를 출력하라. 2월의 윤년 여부는 연습 문제 2의 `isLeapYear()`로 판별한다. 문제 전문과 실행 예시는 [연습 문제 3](Exercises.ko.md#연습-문제-3-월별-날짜-수-계산)에 있다.

### 풀이

**접근 방법:** 2월만 윤년 여부에 따라 29일 또는 28일이고, 나머지 달은 30일인 4, 6, 9, 11월을 `switch`로 고르고 그 밖의 달을 31일로 처리한다.

- **`GetDaysOfMonth()`:** 풀이 코드의 이 함수는 연도 대신 윤년 여부(`detect`)와 월을 매개변수로 받는다. `month`가 2이면 `detect`가 참일 때 29, 거짓일 때 28을 반환하고, 그 밖의 달은 `switch`에서 `case 4`, `case 6`, `case 9`, `case 11`을 한데 묶어 30을, `default`에서 31을 반환한다. 여러 `case` 레이블을 이어 쓰면 어느 레이블로 들어와도 같은 문장을 실행한다.
- **중첩된 `if-else`:** `if (month == 2)` 안의 `if (detect) ... else ...`는 중괄호 없이 쓰였다. `else`는 짝이 없는 가장 가까운 `if`와 짝을 이루므로 첫 번째 `else`는 `if (detect)`에, 두 번째 `else`는 `if (month == 2)`에 연결되어 의도대로 동작한다.
- **`main()`:** 연도와 월을 읽은 뒤 `GetDaysOfMonth(isLeapYear(year), month)`처럼 `isLeapYear()`의 반환값을 곧바로 인수로 넘긴다. 인수인 함수 호출이 먼저 평가되어 1 또는 0이 되고, 그 값이 `detect`로 전달된다([6장 2.5절](Concepts_Lecture.ko.md#25-함수-호출)).

**코드:** [Lab_Q3.c](../../Coursework/Lab06_Functions/Lab_Q3.c)

```c
/**
 * @file    A10104-1_C06Q3.c
 * @brief   Q3. 월별 날짜 수 계산
 * @author  박철원 (Cheolwon Park)
 * @date    2024-04-17
 * 
 * @note    소스 코드에 사용된 scanf_s는 Visual Studio 이외의
 *          IDE에서 실행이 불가할 수 있음에 주의하시기 바랍니다.
 */

#include <stdio.h>

int GetDaysOfMonth(int detect, int month)
{
    if (month == 2)
        if (detect)
            return 29;
        else
            return 28;
    else
        switch (month) {
        case 4:
        case 6:
        case 9:
        case 11:
            return 30;
        default:
            return 31;
        }
}

int isLeapYear(int year)
{
    return ((year % 4) == 0) ? ((year % 100) == 0 ? ((year % 400) == 0 ? 1 : 0) : 1) : 0;
}

int main()
{
    int year, month, days;

    printf("연도와 월을 입력하세요: ");
    scanf_s(" %d %d", &year, &month);

    days = GetDaysOfMonth(isLeapYear(year), month);

    printf("%d년 %d월은 %d일까지 있습니다.", year, month, days);

    return 0;
}
```

**실행 결과:** `-Dscanf_s=scanf`로 컴파일하여 실행 예시의 네 입력을 차례로 넣으면 네 실행 예시와 같은 결과가 나온다. 출력 끝에 줄바꿈을 하지 않으므로 터미널에서는 다음 프롬프트가 같은 줄에 이어진다.

```text
연도와 월을 입력하세요: 2017 4
2017년 4월은 30일까지 있습니다.
```

```text
연도와 월을 입력하세요: 2020 8
2020년 8월은 31일까지 있습니다.
```

```text
연도와 월을 입력하세요: 2000 2
2000년 2월은 29일까지 있습니다.
```

```text
연도와 월을 입력하세요: 2100 2
2100년 2월은 28일까지 있습니다.
```

> **참고:** **함수의 인터페이스.** 문제는 `GetDaysOfMonth()`가 연도와 월을 받도록 정했지만, 풀이 코드는 윤년 판별을 호출하는 쪽에 맡기고 윤년 여부와 월을 받는다. 결과는 같지만, 연도를 받는 형태로 쓰면 [6장 2.5절](Concepts_Lecture.ko.md#25-함수-호출)의 예제처럼 함수 안에서 `isLeapYear(year)`를 호출하므로 호출하는 쪽이 윤년 판별을 알 필요가 없다.

> **주의:** 월을 검사하지 않으므로 1~12 밖의 값을 입력해도 `default`로 처리되어 31일로 출력된다. 예를 들어 `2024 13`을 입력하면 "2024년 13월은 31일까지 있습니다."가 출력된다.
