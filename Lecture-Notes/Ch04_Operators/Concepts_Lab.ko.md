## 1. 연산자와 피연산자

**연산자(operator)** 는 연산을 요구할 때 쓰는 기호이고, **피연산자(operand)** 는 연산이 적용되는 값이다. `4 + 3`에서 `+`는 연산자이고 4와 3은 피연산자이다([4장 1.2절](Concepts_Lecture.ko.md#12-연산자와-피연산자)). C의 연산자는 다음과 같이 분류된다.

- **산술 연산자:** `+`, `-`, `*`, `/`, `%`, 부호 연산자 `-`
- **대입 연산자:** `=`, `+=`, `-=`, `*=`, `/=` 등
- **증감 연산자:** `++`, `--`
- **관계 연산자:** `<`, `<=`, `>`, `>=`, `==`, `!=`
- **논리 연산자:** `!`, `&&`, `||`
- **조건 연산자:** `? :`
- **비트 연산자:** `&`, `|`, `^`, `~`, `<<`, `>>` ([4장 6절](Concepts_Lecture.ko.md#6-비트-연산자))
- **기타 연산자:** 콤마 `,`, 형 변환 `(type)`, `sizeof`

## 2. 산술 연산자와 대입 연산자

### 2.1 산술 연산자

산술 연산자는 일반적인 사칙연산에 쓰는 연산자이다.

| 연산자 | 연산의 예 | 의미 | 결합 방향 |
|:---:|:---:|:-----|:---:|
| `+` | `4 + 3` | 덧셈 | 왼쪽 → 오른쪽 |
| `-` | `4 - 3` | 뺄셈 | 왼쪽 → 오른쪽 |
| `*` | `4 * 3` | 곱셈 | 왼쪽 → 오른쪽 |
| `/` | `4 / 3` | 나눗셈 | 왼쪽 → 오른쪽 |
| `%` | `4 % 3` | 나머지 | 왼쪽 → 오른쪽 |

*표 1. 산술 연산자*

두 피연산자가 모두 정수이면 `/`는 소수 부분을 버린 몫을 구하므로 `4 / 3`은 1이고, `%`는 나머지를 구하므로 `4 % 3`은 1이다. `%`는 정수에만 쓸 수 있다([4장 2.2절](Concepts_Lecture.ko.md#22-정수-나눗셈-vs-실수-나눗셈), [2.3절](Concepts_Lecture.ko.md#23-나머지-연산자)).

### 2.2 대입 연산자와 복합 대입 연산자

대입 연산자 `=`는 오른쪽의 값을 왼쪽 변수의 메모리에 저장한다. `int a = 3; int b = 5; a = b;`를 실행하면 `a`에 `b`의 값 5가 저장되고 `b`는 그대로 5이다. 대입 연산자와 산술 연산자를 합친 **복합 대입 연산자(compound assignment operator)** 는 변수의 현재 값으로 연산한 결과를 다시 그 변수에 저장한다([4장 7.1절](Concepts_Lecture.ko.md#71-단순-대입과-복합-대입)).

```c
#include <stdio.h>

int main(void)
{
    int a = 15;
    int b = 20;

    a += b;     // same as a = a + b;
    printf("Result : %d \n", a);

    return 0;
}
```

```text
Result : 35 
```

| 복합 대입 | 같은 뜻의 대입 |
|:---:|:---:|
| `a += b` | `a = a + b` |
| `a -= b` | `a = a - b` |
| `a *= b` | `a = a * b` |
| `a /= b` | `a = a / b` |
| `a %= b` | `a = a % b` |

*표 2. 복합 대입 연산자와 같은 뜻의 대입*

`a *= b + 1`은 `a = a * b + 1`이 아니라 `a = a * (b + 1)`과 같다. 복합 대입 연산자는 콤마 연산자 다음으로 우선순위가 낮으므로 오른쪽 수식 전체가 먼저 계산된다.

## 3. 증감 연산자

### 3.1 전위와 후위

**증감 연산자(increment and decrement operator)** `++`와 `--`는 변수의 값을 1만큼 늘리거나 줄인다. 연산자를 변수 앞에 쓰는 **전위(prefix)** 와 뒤에 쓰는 **후위(postfix)** 는 수식 안에서 값을 쓰는 시점이 다르다([4장 3.1절](Concepts_Lecture.ko.md#31-전위-vs-후위)).

| 연산자 | 연산의 예 | 의미 |
|:---:|:-----|:-----|
| `++a` | `printf("%d", ++a)` | 먼저 1 증가한 뒤, 증가한 값을 연산에 쓴다 |
| `a++` | `printf("%d", a++)` | 현재 값을 먼저 연산에 쓰고, 그 뒤 1 증가한다 |
| `--b` | `printf("%d", --b)` | 먼저 1 감소한 뒤, 감소한 값을 연산에 쓴다 |
| `b--` | `printf("%d", b--)` | 현재 값을 먼저 연산에 쓰고, 그 뒤 1 감소한다 |

*표 3. 전위와 후위 증감 연산자*

### 3.2 단독 사용과 수식 안의 사용

다음 프로그램은 `a = 3`에서 시작하는 여덟 가지 경우를 비교한다.

```c
#include <stdio.h>

int main(void)
{
    int a, b;

    a = 3; a + 1;          printf("1. a: %d\n", a);        // the result of a + 1 is discarded
    a = 3; a = a + 1;      printf("2. a: %d\n", a);
    a = 3; ++a;            printf("3. a: %d\n", a);
    a = 3; a++;            printf("4. a: %d\n", a);
    a = 3; b = ++a;        printf("5. %d, %d\n", a, b);    // increment first, then use
    a = 3; b = a++;        printf("6. %d, %d\n", a, b);    // use first, then increment
    a = 3; b = ++a * 3;    printf("7. %d, %d\n", a, b);
    a = 3; b = a++ * 3;    printf("8. %d, %d\n", a, b);

    return 0;
}
```

```text
1. a: 3
2. a: 4
3. a: 4
4. a: 4
5. 4, 4
6. 4, 3
7. 4, 12
8. 4, 9
```

- **1과 2:** `a + 1;`은 4를 계산하지만 어디에도 저장하지 않으므로 `a`는 3 그대로이다. 컴파일러는 이 문장에 "expression result unused" 경고를 낸다. 값을 바꾸려면 2처럼 대입해야 한다.
- **3과 4:** 증감 연산자를 단독 문장으로 쓰면 전위와 후위의 결과가 같다. 두 경우 모두 `a`가 1 증가하여 4가 된다([4장 3.2절](Concepts_Lecture.ko.md#32-단독-사용-vs-수식-내-사용)).
- **5와 6:** 수식 안에서는 차이가 난다. `b = ++a`는 `a`를 4로 증가시킨 뒤 4를 `b`에 대입하고, `b = a++`는 `a`의 현재 값 3을 `b`에 대입한 뒤 `a`를 4로 증가시킨다.
- **7과 8:** `++a * 3`은 4 × 3 = 12이고, `a++ * 3`은 증가하기 전의 3을 써서 3 × 3 = 9이다. 두 경우 모두 문장이 끝나면 `a`는 4이다.

> **주의:** `a = a++;`이나 `printf("%d %d", a, a++);`처럼 한 수식 안에서 같은 변수를 증감하면서 그 변수를 다시 쓰거나 대입하면 정의되지 않은 동작이 된다([4장 3.3절](Concepts_Lecture.ko.md#33-사용-제한)).

## 4. 관계 연산자와 논리 연산자

### 4.1 관계 연산자

**관계 연산자(relational operator)** 는 두 피연산자의 크기 관계를 비교하여, 참이면 1, 거짓이면 0을 `int`형 값으로 낸다([4장 4.1절](Concepts_Lecture.ko.md#41-비교-연산자)).

| 연산자 | 연산의 예 | 의미 |
|:---:|:---:|:-----|
| `<` | `a < b` | a가 b보다 작은가 |
| `>` | `a > b` | a가 b보다 큰가 |
| `==` | `a == b` | a와 b가 같은가 |
| `!=` | `a != b` | a와 b가 같지 않은가 |
| `<=` | `a <= b` | a가 b보다 작거나 같은가 |
| `>=` | `a >= b` | a가 b보다 크거나 같은가 |

*표 4. 관계 연산자*

### 4.2 논리 연산자

**논리 연산자(logical operator)** 는 AND, OR, NOT을 나타내며, 결과는 관계 연산자와 같이 1 또는 0이다. 피연산자는 0이면 거짓, 0이 아니면 참으로 판단한다([4장 5.1절](Concepts_Lecture.ko.md#51-and-or-not)).

| 연산자 | 이름 | 연산의 예 | 의미 |
|:---:|:-----|:---:|:-----|
| `&&` | 논리 AND | `식1 && 식2` | 두 식이 모두 참이면 1 |
| `\|\|` | 논리 OR | `식1 \|\| 식2` | 두 식 중 하나라도 참이면 1 |
| `!` | 논리 NOT | `!a` | a가 참이면 0, 거짓이면 1 |

*표 5. 논리 연산자*

| 식1 | 식2 | `식1 && 식2` | `식1 \|\| 식2` | `!식1` |
|:---:|:---:|:---:|:---:|:---:|
| 참 | 참 | 1 | 1 | 0 |
| 참 | 거짓 | 0 | 1 | 0 |
| 거짓 | 참 | 0 | 1 | 1 |
| 거짓 | 거짓 | 0 | 0 | 1 |

*표 6. 논리 연산자의 진리표*

다음 프로그램은 관계 연산자와 논리 연산자, 조건 연산자(5.1절)의 결과를 출력한다.

```c
#include <stdio.h>

int main(void)
{
    int a = 15, b = 20;
    int c;

    printf("Result : %d \n", a == b);   // false: 0
    printf("Result : %d \n", a < 20);   // true: 1

    c = (a < b) && (a > b);
    printf("Result: %d \n", c);
    c = (a < b) || (a > b);
    printf("Result: %d \n", c);

    c = (a < b) ? a : b;
    printf("Result: %d \n", c);
    printf("Result: %d \n", (a > b) ? a : b);

    return 0;
}
```

```text
Result : 0 
Result : 1 
Result: 0 
Result: 1 
Result: 15 
Result: 20 
```

`(a < b) && (a > b)`는 참 && 거짓이므로 0이고, `(a < b) || (a > b)`는 참 || 거짓이므로 1이다. `&&`는 왼쪽 식이 거짓이면, `||`는 왼쪽 식이 참이면 오른쪽 식을 계산하지 않는다([4장 5.3절](Concepts_Lecture.ko.md#53-단락-평가)).

## 5. 조건 연산자와 기타 연산자

### 5.1 조건 연산자

**조건 연산자(conditional operator)** `조건 ? 값1 : 값2`는 조건이 참이면 `?` 뒤의 값1을, 거짓이면 `:` 뒤의 값2를 결과로 고른다. 피연산자가 세 개이므로 삼항 연산자라고도 한다([4장 8.1절](Concepts_Lecture.ko.md#81-삼항-연산자)). 4.2절 프로그램에서 `c = (a < b) ? a : b;`는 15 < 20이 참이므로 `a`의 값 15를 `c`에 대입하고, `(a > b) ? a : b`는 거짓이므로 20을 낸다. 조건 연산자는 식이므로 `printf`의 인자처럼 값이 필요한 자리에 바로 쓸 수 있다.

### 5.2 콤마 연산자, 형 변환 연산자, sizeof

```c
a = 10, b = 5;   // assigns 10 to a, then 5 to b
(int) ave;       // makes a temporary int value from the double ave (the fraction is dropped)
sizeof(int)      // the memory size used by the type int
```

- **콤마 연산자(comma operator):** 왼쪽 식부터 차례로 계산하며, 전체 식의 값은 마지막 식의 값이다.
- **형 변환 연산자(cast operator):** `(int) ave`는 실수형 변수 `ave`의 값에서 소수 부분을 버린 `int`형의 임시 값을 새로 만들어 쓴다. `ave` 자체의 값은 바뀌지 않는다([4장 9.2절](Concepts_Lecture.ko.md#92-캐스트-연산자)).
- **`sizeof`:** 타입이나 값이 차지하는 메모리의 크기를 바이트 수로 낸다([3장 7절](../Ch03_Data-Types-and-Variables/Concepts_Lecture.ko.md#7-sizeof-연산자)).

## 6. 연산자 우선순위와 결합 방향

수식에 연산자가 여러 개 있으면 **우선순위(precedence)** 가 높은 연산자부터 계산하고, 우선순위가 같으면 **결합 방향(associativity)** 에 따라 계산한다([4장 10절](Concepts_Lecture.ko.md#10-연산자-우선순위와-결합-방향)).

| 우선순위 | 연산자 | 결합 방향 |
|:---:|:-----|:---:|
| 1 | `()` `[]` `.` `->` 후위 `++` `--` | 왼쪽 → 오른쪽 |
| 2 | `!` `~` 전위 `++` `--` 단항 `+` `-` `(자료형)` `*` `&` `sizeof` | 오른쪽 → 왼쪽 |
| 3 | `*` `/` `%` | 왼쪽 → 오른쪽 |
| 4 | `+` `-` | 왼쪽 → 오른쪽 |
| 5 | `<<` `>>` | 왼쪽 → 오른쪽 |
| 6 | `<` `<=` `>` `>=` | 왼쪽 → 오른쪽 |
| 7 | `==` `!=` | 왼쪽 → 오른쪽 |
| 8 | `&` | 왼쪽 → 오른쪽 |
| 9 | `^` | 왼쪽 → 오른쪽 |
| 10 | `\|` | 왼쪽 → 오른쪽 |
| 11 | `&&` | 왼쪽 → 오른쪽 |
| 12 | `\|\|` | 왼쪽 → 오른쪽 |
| 13 | `?:` | 오른쪽 → 왼쪽 |
| 14 | `=` `+=` `-=` `*=` `/=` `%=` `&=` `\|=` `^=` `<<=` `>>=` | 오른쪽 → 왼쪽 |
| 15 | `,` | 왼쪽 → 오른쪽 |

*표 7. C 연산자의 우선순위와 결합 방향*

후위 증감 연산자는 1순위에, 전위 증감 연산자와 단항 부호 연산자는 2순위에 속한다. 2순위의 단항 연산자는 오른쪽에서 왼쪽으로 결합하므로 `-!x`는 `-(!x)`로 계산된다. 2순위의 `*`와 `&`는 포인터의 역참조와 주소 연산자이며 8장에서 다룬다. 우선순위가 헷갈리는 수식은 괄호로 계산 순서를 분명히 하는 것이 좋다.

## 7. 실습 문제

각 프로그램은 `gcc -std=c99 -Wall`로 경고 없이 컴파일되며, 출력은 실제로 실행한 결과이다.

### 7.1 증감 연산자의 결과 예측

**문제:** 다음 프로그램의 실행 결과를 예측하라.

```c
#include <stdio.h>

int main(void)
{
    int n = 2, b = 0;

    printf(" %d \n", ++n);
    printf(" %d \n", n++);
    printf(" %d \n", n + 1);
    printf(" %d \n", n);
    printf("------- \n");
    printf(" %d \n", ++n * 3);
    printf(" %d \n", n++ * 3);
    printf(" %d \n", n);
    printf("------- \n");
    printf(" %d \n", b = n++);
    printf(" %d, %d \n", b, n);
    printf(" %d \n", b = ++n / 2);
    printf(" %d, %d \n", b, n);

    return 0;
}
```

**풀이:** 각 문장이 출력하는 값과 문장이 끝난 뒤의 `n`, `b`를 차례로 추적한다.

| 문장 | 출력 | 실행 후 `n` | 실행 후 `b` |
|:-----|:---:|:---:|:---:|
| `++n` | 3 | 3 | 0 |
| `n++` | 3 | 4 | 0 |
| `n + 1` | 5 | 4 | 0 |
| `n` | 4 | 4 | 0 |
| `++n * 3` | 15 | 5 | 0 |
| `n++ * 3` | 15 | 6 | 0 |
| `n` | 6 | 6 | 0 |
| `b = n++` | 6 | 7 | 6 |
| `b, n` | 6, 7 | 7 | 6 |
| `b = ++n / 2` | 4 | 8 | 4 |
| `b, n` | 4, 8 | 8 | 4 |

*표 8. 문장마다의 출력과 변수의 값*

- `n + 1`은 5를 출력하지만 `n`에 대입하지 않으므로 `n`은 4 그대로이다.
- `++n * 3`은 `n`을 5로 증가시킨 뒤 5 × 3 = 15이고, `n++ * 3`은 증가하기 전의 5를 써서 15를 낸 뒤 `n`을 6으로 증가시킨다.
- 대입식 `b = n++`의 값은 대입된 값 6이다.
- `b = ++n / 2`에서 `n`은 8이 되고, 정수 나눗셈 8 / 2 = 4가 `b`에 대입된다.

```text
 3 
 3 
 5 
 4 
------- 
 15 
 15 
 6 
------- 
 6 
 6, 7 
 4 
 4, 8 
```

### 7.2 몫과 나머지

**문제:** 두 정수 `vOne`, `vTwo`를 입력받아 몫(quotient)과 나머지(remainder)를 출력하라.

**풀이:** 정수끼리의 나눗셈 `/`는 몫을, `%`는 나머지를 구한다. 두 결과는 항상 `vOne == (vOne / vTwo) * vTwo + vOne % vTwo`를 만족한다.

```c
#define _CRT_SECURE_NO_WARNINGS  // allows scanf in Visual Studio
#include <stdio.h>

int main(void)
{
    int vOne, vTwo;

    printf("Input two values: ");
    scanf("%d %d", &vOne, &vTwo);

    printf("quotient: %d\n", vOne / vTwo);     // integer division drops the fraction
    printf("remainder: %d\n", vOne % vTwo);

    return 0;
}
```

```text
Input two values: 13 3
quotient: 4
remainder: 1
```

> **주의:** C99부터 정수 나눗셈은 0 쪽으로 버림하므로, 음수를 나누면 몫과 나머지가 모두 음수가 된다. `-13`과 `3`을 입력하면 몫은 -4, 나머지는 -1이다. 또 `vTwo`에 0을 입력하면 0으로 나누게 되어 정의되지 않은 동작이 된다.

```text
Input two values: -13 3
quotient: -4
remainder: -1
```

### 7.3 조건 연산자로 큰 수 출력

**문제:** 두 정수를 입력받아 큰 수를 출력하라. 조건 연산자를 쓰고, 필요하면 변수를 추가로 만든다.

**풀이:** 조건 `a > b`가 참이면 `a`를, 거짓이면 `b`를 고르는 `(a > b) ? a : b`의 값을 변수 `max`에 대입한다. 두 수가 같으면 조건이 거짓이므로 `b`가 선택되지만 값은 같다.

```c
#define _CRT_SECURE_NO_WARNINGS  // allows scanf in Visual Studio
#include <stdio.h>

int main(void)
{
    int a, b, max;

    printf("input two values: ");
    scanf("%d %d", &a, &b);

    max = (a > b) ? a : b;     // the larger of a and b
    printf("MAX: %d\n", max);

    return 0;
}
```

```text
input two values: -3 89
MAX: 89
```

```text
input two values: -3 -23
MAX: -3
```

세 정수 중 가장 큰 값을 조건 연산자만으로 구하는 문제는 [HW03 문제 4](../../Coursework/HW03_Control-Statements-I/Assignment-Explanation.ko.md#5-문제-4-대소-비교)에서 다룬다.

### 7.4 관계, 논리 연산과 sizeof의 결과 예측

**문제:** 다음 코드의 실행 결과를 예측하라.

```c
#include <stdio.h>

int main(void)
{
    int no = 100, count = 20;
    char ch = 'A';

    printf(" %d", no > count);
    printf(" %d", no < count * 4);
    printf(" %d", (no != 100) || (count >= 20));
    printf(" %d", (no <= 100) && (count > 20));
    printf("\n------\n");
    printf(" %d \n", !(no > count));
    printf(" %zu \n", sizeof(char));
    printf(" %zu \n", sizeof(ch));
    printf(" %zu \n", sizeof('A'));
    printf(" %zu \n", sizeof(3.2));

    return 0;
}
```

**풀이:**

- `no > count`는 100 > 20이므로 1이다.
- `no < count * 4`는 `*`가 `<`보다 먼저 계산되어 100 < 80이므로 0이다.
- `(no != 100) || (count >= 20)`은 거짓 || 참이므로 1이다.
- `(no <= 100) && (count > 20)`은 참 && 거짓이므로 0이다.
- `!(no > count)`는 !1이므로 0이다.
- `sizeof(char)`와 `sizeof(ch)`는 1이고, 문자 상수 `'A'`의 타입은 `int`이므로 `sizeof('A')`는 4이며, 실수 상수 `3.2`의 타입은 `double`이므로 `sizeof(3.2)`는 8이다([3장 실습 4절](../Ch03_Data-Types-and-Variables/Concepts_Lab.ko.md#4-sizeof-연산자)).

```text
 1 0 1 0
------
 0 
 1 
 1 
 4 
 8 
```

`sizeof`의 결과는 `size_t`형이므로 C99부터는 `%zu`로 출력한다. 같은 형태로 변수 값과 `sizeof`를 바꾼 문제가 [HW03 문제 1](../../Coursework/HW03_Control-Statements-I/Assignment-Explanation.ko.md#2-문제-1-연산자의-결과값)에 있다.

## 점검 문제

1. **증감 연산자:** `int x = 5, y;`일 때 `y = x-- * 2;`를 실행한 뒤의 `x`와 `y`를 쓰라.

   <details>
   <summary>정답</summary>

   후위 감소이므로 감소하기 전의 5를 써서 `y`는 5 × 2 = 10이고, 문장이 끝난 뒤 `x`는 4이다.

   </details>

2. **복합 대입:** `int a = 6, b = 2;`일 때 `a /= b + 1;`을 실행한 뒤의 `a`를 쓰라.

   <details>
   <summary>정답</summary>

   복합 대입 연산자는 오른쪽 수식 전체를 먼저 계산하므로 `a = a / (b + 1)`, 즉 6 / 3 = 2이다.

   </details>

3. **논리 연산:** `int a = 0, b = 5;`일 때 `a && (b = 10)`을 계산한 뒤 `b`의 값은 무엇인가?

   <details>
   <summary>정답</summary>

   `a`가 0(거짓)이므로 `&&`는 오른쪽 식을 계산하지 않고 결과 0을 낸다. 따라서 `b = 10`은 실행되지 않아 `b`는 5 그대로이다.

   </details>

4. **우선순위:** `int x = 3;`일 때 `x + 2 > 4 && x * 2 == 6`의 값을 구하고, 계산 순서를 괄호로 나타내라.

   <details>
   <summary>정답</summary>

   `((x + 2) > 4) && ((x * 2) == 6)`으로 계산되며, 5 > 4는 참, 6 == 6은 참이므로 값은 1이다. 산술 연산자가 관계 연산자보다, 관계 연산자가 논리 연산자보다 우선순위가 높다.

   </details>

5. **나머지:** 양의 정수 `n`의 일의 자리 숫자와 십의 자리 숫자를 구하는 수식을 쓰라.

   <details>
   <summary>정답</summary>

   일의 자리는 `n % 10`, 십의 자리는 `n / 10 % 10`이다. `/`와 `%`는 우선순위가 같고 왼쪽에서 오른쪽으로 결합하므로 `n / 10 % 10`은 `(n / 10) % 10`으로 계산된다. 예를 들어 n = 357이면 일의 자리는 7, 십의 자리는 35 % 10 = 5이다.

   </details>
