## 연습 문제 1: 데이터 타입에 대한 설명

**교재 문항:** 3장 연습 문제 1번

**문제:** 데이터 타입에 대한 다음 설명 중 잘못된 것을 모두 고르라.

- ① 플랫폼에 관계없이 데이터 타입의 크기는 정해져 있다.
- ② 문자형으로는 `char`형이 있고, 크기는 2바이트이다.
- ③ 실수형도 부호 있는 실수형과 부호 없는 실수형이 있다.
- ④ 정수형은 데이터 타입의 크기가 클수록 유효 범위가 커진다.
- ⑤ `char`형도 정수형으로 볼 수 있다.
- ⑥ 정수형 변수에 데이터 타입의 최댓값보다 큰 값을 저장하면 변수의 크기가 늘어난다.
- ⑦ 정수형 변수에 데이터 타입의 최솟값보다 작은 값을 저장하면 유효 범위 내의 값으로 설정된다.
- ⑧ 실수형 변수에 표현 가능한 실수보다 큰 값을 저장하면 0으로 설정된다.
- ⑨ 실수의 정밀도는 지수 부분에 의해서 결정된다.
- ⑩ 실수는 항상 정확한 값의 표현이 가능하다.

## 연습 문제 5: 상수에 대한 설명

**교재 문항:** 3장 연습 문제 5번

**문제:** 상수에 대한 설명 중 잘못된 것을 모두 고르라.

- ① 상수는 값을 변경할 수 없으므로 `=`의 좌변에 올 수 없다.
- ② 상수는 값이 메모리에 저장되지 않고 한 번만 사용된 다음 없어져 버린다.
- ③ 이름이 있는 상수를 리터럴 상수라고 한다.
- ④ 리터럴 상수를 이용하면 코드가 알아보기 쉽고 수정하기 쉽다.
- ⑤ 매크로 상수를 정의할 때는 데이터 타입이 필요하다.
- ⑥ 문자열 안에 포함된 매크로 상수는 대치되지 않는다.
- ⑦ `const` 변수는 값을 변경할 수 없으므로 메모리에 할당되지 않는다.
- ⑧ `const` 변수를 변경하면 컴파일 에러가 발생한다.

```c

    char a = CHAR_MIN - 1;     // CHAR_MIN은 -128로 정의

    printf("%d, %d, %x\n", a, b, ch);
}
```

## 연습 문제 11: 위치 에너지의 계산

**교재 문항:** 3장 프로그래밍 과제 3번

**문제:** 질량과 높이를 입력받아 위치 에너지를 구하는 프로그램을 작성하라. 질량은 kg 단위, 높이는 m 단위로 입력받으며, 위치 에너지는 9.8 × 질량 × 높이로 구한다.

**실행 예시:**

```text
질량(kg)? 10
높이(m)? 5
위치에너지: 490.00 J
```

> **참고:** 질량과 높이는 실수로 입력받을 수도 있다. `float`형 변수를 입력받을 때는 형식 지정자로 `%f`를, `double`형 변수를 입력받을 때는 `%lf`를 사용한다. 입력할 때 소수점 이하를 생략하면 소수점 이하를 0으로 간주한다.

**[풀이](Solutions.ko.md#연습-문제-11-위치-에너지의-계산)**
