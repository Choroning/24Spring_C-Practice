## 연습 문제 1: 이차원 평면의 점 좌표 사분면 판별

**교재 문항:** 182쪽 3번 문제

**문제:** 점의 좌표 (x, y)를 입력받아 원점, x축 위, y축 위, 제1~4사분면 중 어디에 있는지 출력하라. 문제 전문과 실행 예시는 [연습 문제 1](Exercises.ko.md#연습-문제-1-이차원-평면의-점-좌표-사분면-판별)에 있다.

### 풀이

**접근 방법:** x의 부호(양수, 0, 음수)로 먼저 세 갈래로 나누고, 각 갈래 안에서 y의 부호로 다시 세 갈래로 나누는 중첩 `if`를 쓴다([5장 2.5절](Concepts_Lecture.ko.md#25-중첩-if)). 3 × 3 = 9가지 조합이 빠짐없이, 겹치지 않게 처리된다.

- **x > 0:** y > 0이면 제1사분면, y = 0이면 x축 위, y < 0이면 제4사분면이다.
- **x = 0:** y > 0이면 y축 위, y = 0이면 원점이고, y < 0이면 `y축 아래`라고 출력한다.
- **x < 0:** y > 0이면 제2사분면, y = 0이면 x축 위, y < 0이면 제3사분면이다.

**코드:** [Lab_Q1.c](../../Coursework/Lab05_Control-Statements/Lab_Q1.c)

```c
/**
 * @file    A10104-1_C05Q1.c
 * @brief   Q1. 이차원 평면의 점 좌표 사분면 판별
 * @author  박철원 (Cheolwon Park)
 * @date    2024-04-02
 * 
 * @note    소스 코드에 사용된 scanf_s는 Visual Studio 이외의
 *          IDE에서 실행이 불가할 수 있음에 주의하시기 바랍니다.
 */

#include <stdio.h>

int main(void)
{
    int posx, posy;

    // 사용자로부터 좌표를 입력받음
    printf("좌표 (x, y)? ");
    scanf_s(" %d %d", &posx, &posy);

    if (posx > 0) {
        if (posy > 0)
            printf("(%d, %d)는 제1사분면에 위치합니다.\n", posx, posy);
        else if (posy == 0)
            printf("(%d, %d)는 x축 위에 위치합니다.\n", posx, posy);
        else
            printf("(%d, %d)는 제4사분면에 위치합니다.\n", posx, posy);
    }
    else if (posx == 0) {
        if (posy > 0)
            printf("(%d, %d)는 y축 위에 위치합니다.\n", posx, posy);
        else if (posy == 0)
            printf("(%d, %d)는 원점에 위치합니다.\n", posx, posy);
        else
            printf("(%d, %d)는 y축 아래에 위치합니다.\n", posx, posy);
    }
    else {  // posx < 0
        if (posy > 0)
            printf("(%d, %d)는 제2사분면에 위치합니다.\n", posx, posy);
        else if (posy == 0)
            printf("(%d, %d)는 x축 위에 위치합니다.\n", posx, posy);
        else
            printf("(%d, %d)는 제3사분면에 위치합니다.\n", posx, posy);
    }

    return 0;
}
```

**실행 결과:** 실행 예시의 다섯 경우에 제2사분면, 제3사분면, y축의 음수 쪽을 더한 여덟 경우를 차례로 실행한 결과이다. 판별 결과는 실행 예시와 같지만 문구는 다르다. 입력 안내가 `좌표 (x, y)? `이고, 좌표를 `(0, 0)`처럼 쉼표 뒤에 공백을 넣어 출력하며, 사분면을 `1사분면 위에`가 아니라 `제1사분면에`로 출력한다.

```text
좌표 (x, y)? 0 0
(0, 0)는 원점에 위치합니다.
좌표 (x, y)? -2 0
(-2, 0)는 x축 위에 위치합니다.
좌표 (x, y)? 0 10
(0, 10)는 y축 위에 위치합니다.
좌표 (x, y)? 3 7
(3, 7)는 제1사분면에 위치합니다.
좌표 (x, y)? -4 1
(-4, 1)는 제2사분면에 위치합니다.
좌표 (x, y)? -3 -8
(-3, -8)는 제3사분면에 위치합니다.
좌표 (x, y)? 8 -2
(8, -2)는 제4사분면에 위치합니다.
좌표 (x, y)? 0 -5
(0, -5)는 y축 아래에 위치합니다.
```

> **참고:** (0, -5)처럼 x가 0이고 y가 음수인 점도 y축 위의 점이다. 코드는 이 경우를 `y축 아래에 위치합니다`로 출력하여 y축의 음수 쪽임을 나타내는데, x축 위의 점은 x의 부호와 관계없이 `x축 위`로 출력하므로 두 축의 표현이 서로 다르다.

> **참고:** **`scanf_s`와 실행 환경.** 연습 문제 1~4의 코드가 쓰는 `scanf_s`는 Visual Studio(MSVC)가 제공하는 함수이다. gcc와 clang이 쓰는 표준 라이브러리 대부분은 이를 제공하지 않으므로, 이 문서의 실행 결과는 코드를 바꾸지 않고 `gcc -std=c99 -Wall -Dscanf_s=scanf`로 `scanf_s`를 `scanf`로 대체하여 컴파일한 것이다. 실행 예시의 `Program ended with exit code: 0`은 프로그램의 출력이 아니라 Xcode 콘솔이 덧붙이는 종료 메시지이다.

## 연습 문제 2: 섭씨와 화씨의 단위 변환

**교재 문항:** 183쪽 5번 문제

**문제:** 정수 온도와 단위 문자(C 또는 F, 대소문자 무관)를 입력받아 섭씨는 화씨로, 화씨는 섭씨로 변환하라. 단위 앞의 공백 유무와 관계없이 입력받아야 하며, 반드시 `switch`문을 쓴다. 문제 전문과 실행 예시는 [연습 문제 2](Exercises.ko.md#연습-문제-2-섭씨와-화씨의-단위-변환)에 있다.

### 풀이

**접근 방법:** 단위 문자를 `switch`의 식으로 쓰고, 대문자와 소문자 case를 연달아 두어 같은 문장을 실행하게 한다([5장 2.7절](Concepts_Lecture.ko.md#27-switch)).

- **입력:** 형식 문자열 `" %d %c"`에서 `%c` 앞의 공백은 0개 이상의 공백 문자를 건너뛰므로, `32C`와 `100 f`가 모두 같은 방식으로 읽힌다.
- **case 레이블:** 67, 99, 70, 102는 각각 `'C'`, `'c'`, `'F'`, `'f'`의 ASCII 코드이다. 문자 상수 `'C'`로 써도 값이 같으며, 문자 상수가 의도를 더 분명히 드러낸다.
- **변환식:** `(double)temp * 9 / 5 + 32`는 캐스트가 먼저 적용되어 모든 연산이 실수로 계산된다. `temp * 9 / 5`처럼 정수로 계산하면 소수 부분이 버려진다. 섭씨 변환 `((double)temp - 32) * 5 / 9`도 같은 이유로 먼저 캐스트한다.
- **출력:** 입력 온도는 `%.0lf`로 소수점 없이, 변환 결과는 `%.2lf`로 소수점 아래 둘째 자리까지 출력한다. 단위 문자가 네 가지가 아니면 `default`에서 오류 메시지를 출력한다.

**코드:** [Lab_Q2.c](../../Coursework/Lab05_Control-Statements/Lab_Q2.c)

```c
/**
 * @file    A10104-1_C05Q2.c
 * @brief   Q2. 섭씨 ↔ 화씨 단위 변환
 * @author  박철원 (Cheolwon Park)
 * @date    2024-04-02
 * 
 * @note    소스 코드에 사용된 scanf_s는 Visual Studio 이외의
 *          IDE에서 실행이 불가할 수 있음에 주의하시기 바랍니다.
 */

#include <stdio.h>

int main()
{
    int temp = 0;
    char tempal = 0;
    double cel = 0, far = 0;

    printf("온도? ");
    scanf_s(" %d %c", &temp, &tempal);

    switch (tempal) {
    case 67:  // 'C'
    case 99:  // 'c'
        //cel = temp;
        far = (double)temp * 9 / 5 + 32;
        printf("%.0lf C == %.2lf F", (double)temp, far);
        break;
    case 70:  // 'F'
    case 102: // 'f'
        //far = temp;
        cel = ((double)temp - 32) * 5 / 9;
        printf("%.0lf F == %.2lf C", (double)temp, cel);
        break;
    default:
        printf("입력 오류! 온도 단위는 C(혹은 c)와 F(혹은 f)만 허용됩니다.");
        break;
    }

    return 0;
}
```

**실행 결과:** 변환 값은 세 실행 예시와 같다. 오류 메시지는 `입력 오류! 온도 단위는 C(혹은 c)와 F(혹은 f)만 허용됩니다.`로 실행 예시와 문구가 다르고, 모든 출력이 줄바꿈 없이 끝난다. 32°C는 32 × 9 / 5 + 32 = 89.6°F, 100°F는 (100 - 32) × 5 / 9 = 37.777...°C이다.

```text
온도? 32C
32 C == 89.60 F
온도? 100 f
100 F == 37.78 C
온도? -28 g
입력 오류! 온도 단위는 C(혹은 c)와 F(혹은 f)만 허용됩니다.
```

> **주의:** MSVC의 `scanf_s`는 `%c`, `%s`, `%[` 변환마다 버퍼 크기를 나타내는 인자를 하나 더 받도록 정의되어 있다. 이 코드의 `scanf_s(" %d %c", &temp, &tempal)`에는 그 인자가 없으므로 `scanf_s`의 규약에 맞지 않으며, `scanf_s`를 그대로 쓰려면 `scanf_s(" %d %c", &temp, &tempal, 1)`처럼 크기 1을 넘겨야 한다. 또 온도는 `%d`로 읽으므로 `32.5C`처럼 소수를 입력하면 32 다음의 `.`이 단위 문자로 읽혀 오류 메시지가 출력된다.

```text
온도? 32.5C
입력 오류! 온도 단위는 C(혹은 c)와 F(혹은 f)만 허용됩니다.
```

## 연습 문제 3: 이차 방정식의 근 계산

**문제:** 정수 계수 a, b, c를 입력받아 판별식 $b^2 - 4ac$의 부호에 따라 허근, 중근, 서로 다른 두 실근을 판별하고 실근을 계산하라. 정수 나눗셈이 일어나지 않게 하고 제곱근은 `sqrt()`로 구한다. 문제 전문과 실행 예시는 [연습 문제 3](Exercises.ko.md#연습-문제-3-이차-방정식의-근-계산)에 있다.

### 풀이

**접근 방법:** 판별식을 먼저 계산하고 `else if` 사다리로 음수, 0, 양수의 세 경우를 나눈다([5장 2.4절](Concepts_Lecture.ko.md#24-else-if)).

- **판별식:** `(b * b) - (4 * a * c)`는 정수로 계산된 뒤 `double` 변수 `cal`에 저장된다. 정수끼리의 곱셈과 뺄셈이므로 값이 정확하고, 그래서 `cal == 0` 비교도 정확하게 동작한다.
- **근:** `(-b + sqrt(cal)) / (2 * a)`에서 `sqrt()`가 `double`을 반환하므로 분자가 실수가 되어 실수 나눗셈이 된다. 중근이면 `sqrt(0)`이 0이므로 `ans1`이 $-\frac{b}{2a}$와 같다.
- **a = 0 처리:** 문제는 $a \neq 0$을 가정하지만, 코드는 `if (a)`로 a가 0인지 먼저 검사하여 0이면 이차 방정식이 아니라는 오류 메시지를 출력한다.
- **출력:** `%g`는 유효 숫자 6자리 안에서 `%f`와 `%e` 중 짧은 형식을 고르고 뒤쪽의 0을 지우므로, 1은 `1`로, 2/3는 `0.666667`로 출력된다.

**코드:** [Lab_Q3.c](../../Coursework/Lab05_Control-Statements/Lab_Q3.c)

```c
/**
 * @file    A10104-1_C05Q3.c
 * @brief   Q3. 이차 방정식의 근 계산
 * @author  박철원 (Cheolwon Park)
 * @date    2024-04-03
 * 
 * @note    소스 코드에 사용된 scanf_s는 Visual Studio 이외의
 *          IDE에서 실행이 불가할 수 있음에 주의하시기 바랍니다.
 */

#include <stdio.h>
#include <math.h>

int main()
{
    int a, b, c;
    double cal, ans1, ans2;

    printf("이차 방정식의 상관계수 a, b, c 입력: ");
    scanf_s(" %d %d %d", &a, &b, &c);

    cal = (b * b) - (4 * a * c);
    ans1 = (-b + sqrt(cal)) / (2 * a);
    ans2 = (-b - sqrt(cal)) / (2 * a);

    if (a) {  // a != 0일 때 이차 방정식으로 계산을 수행
        if (cal < 0)
            printf("입력하신 이차 방정식은 허근을 갖습니다.");
        else if (cal == 0)
            printf("입력하신 이차 방정식의 중근 x = %g입니다.", ans1);
        else
            printf("입력하신 이차 방정식의 해는 x1 = %g, x2 = %g입니다.", ans1, ans2);
    }
    else
        printf("입력 오류! a = 0일 때 이차 방정식이 성립하지 않습니다.");

    return 0;
}
```

**실행 결과:** 근의 값과 판별 결과는 세 실행 예시와 같다. 문구는 `입력하신 이차 방정식의 해는 x1 = 1, x2 = -0.666667입니다.`, `입력하신 이차 방정식의 중근 x = 0.666667입니다.`처럼 실행 예시와 다르고, 줄바꿈 없이 끝난다. 마지막 실행은 a에 0을 입력한 경우이다.

```text
이차 방정식의 상관계수 a, b, c 입력: 3 -1 -2
입력하신 이차 방정식의 해는 x1 = 1, x2 = -0.666667입니다.
이차 방정식의 상관계수 a, b, c 입력: 9 -12 4
입력하신 이차 방정식의 중근 x = 0.666667입니다.
이차 방정식의 상관계수 a, b, c 입력: 1 1 1
입력하신 이차 방정식은 허근을 갖습니다.
이차 방정식의 상관계수 a, b, c 입력: 0 2 1
입력 오류! a = 0일 때 이차 방정식이 성립하지 않습니다.
```

> **참고:** 코드는 판별식의 부호를 검사하기 전에 두 근을 미리 계산한다. 판별식이 음수이면 `sqrt()`가 `nan`을 반환하고, a가 0이면 0으로 나누게 되지만, 이 값들은 출력되지 않고 실수 연산이므로 프로그램이 멈추지도 않는다. 근은 판별식이 0 이상이고 a가 0이 아님을 확인한 뒤에 계산하는 편이 논리적으로 깔끔하다.

## 연습 문제 4: 정수의 합과 평균 계산

**문제:** `while`문으로 정수를 반복 입력받다가 `-1`이 입력되면 멈추고, `-1`을 뺀 입력값의 합과 평균(소수점 아래 둘째 자리)을 출력하라. 문제 전문과 실행 예시는 [연습 문제 4](Exercises.ko.md#연습-문제-4-정수의-합과-평균-계산)에 있다.

### 풀이

**접근 방법:** `while (1)` 무한 반복 안에서 입력받은 값이 감시값 `-1`이면 `break`로 빠져나가고, 아니면 누적기 `sum1`과 카운터 `count`를 갱신한다([5장 5.1절](Concepts_Lecture.ko.md#51-카운터와-누적기)).

- **감시값 처리:** 값을 누적하기 전에 `-1`인지 검사하므로 `-1`은 합과 개수에 들어가지 않는다. 0은 감시값이 아니므로 다른 값처럼 합과 개수에 포함된다.
- **평균:** `(double)sum1 / count`로 실수 나눗셈을 하고, `%.2f`로 소수점 아래 둘째 자리까지 출력한다. 196 / 5 = 39.2이다.

**코드:** [Lab_Q4.c](../../Coursework/Lab05_Control-Statements/Lab_Q4.c)

```c
/**
 * @file    A10104-2_C05Q1.c
 * @brief   Q1. 정수의 합과 평균 계산
 * @author  박철원 (Cheolwon Park)
 * @date    2024-04-09
 * 
 * @note    소스 코드에 사용된 scanf_s는 Visual Studio 이외의
 *          IDE에서 실행이 불가할 수 있음에 주의하시기 바랍니다.
 */

#include <stdio.h>

int main()
{
    int num = -1, sum1 = 0, count = 0;
    double ave = 0;
    
    while (1) {
        printf("정수 입력(종료: -1): ");
        scanf_s(" %d", &num);
        
        if (num == -1)
            break;
        else {
            sum1 = sum1 + num;
            count++;
        }
    }
    ave = (double)sum1 / count;
    printf("입력된 수의 합: %d\n", sum1);
    printf("입력된 수의 평균: %.2f\n", ave);

    return 0;
}
```

**실행 결과:** 합과 평균은 실행 예시와 같다. 결과 문구는 `입력된 정수의 합`이 아니라 `입력된 수의 합`, `입력된 수의 평균`이다.

```text
정수 입력(종료: -1): 10
정수 입력(종료: -1): 27
정수 입력(종료: -1): 61
정수 입력(종료: -1): 0
정수 입력(종료: -1): 98
정수 입력(종료: -1): -1
입력된 수의 합: 196
입력된 수의 평균: 39.20
```

> **주의:** 처음부터 `-1`을 입력하면 `count`가 0인 채로 `(double)sum1 / count`, 즉 0.0 / 0을 계산하므로 평균이 `nan`으로 출력된다. 5장 3.2절의 감시값 예제처럼 `if (count > 0)`으로 입력이 하나 이상일 때만 평균을 출력하면 이 경우를 처리할 수 있다.

```text
정수 입력(종료: -1): -1
입력된 수의 합: 0
입력된 수의 평균: nan
```

## 연습 문제 5: 삼각형 출력 메뉴

**문제:** 메뉴 1~4로 왼쪽 정렬 삼각형, 오른쪽 정렬 삼각형, 왼쪽 정렬 역삼각형, 오른쪽 정렬 역삼각형을 고르고 크기(줄 수)를 입력받아 `*`로 출력하며, 5를 고르면 종료하는 프로그램을 예시 코드의 빈칸을 채워 완성하라. 잘못된 메뉴는 다시 입력받는다. 문제 전문과 실행 예시는 [연습 문제 5](Exercises.ko.md#연습-문제-5-삼각형-출력-메뉴)에 있다.

### 풀이

**접근 방법:** 바깥의 `while (1)`이 메뉴를 반복해서 보여 주고, 안쪽의 `do-while`이 올바른 메뉴를 받을 때까지 입력을 반복한다([5장 5.4절](Concepts_Lecture.ko.md#54-메뉴-기반-프로그램)). 삼각형은 `switch`의 각 case에서 중첩 `for`로 그린다. 바깥 반복의 i번째 줄(i = 1부터 size까지)마다 공백과 별의 개수를 정하는 것이 핵심이다([5장 3.4절](Concepts_Lecture.ko.md#34-중첩-반복문)).

- **메뉴 입력:** `scanf(" %c", &menu)`로 문자 하나를 읽고, `'1'`~`'5'` 밖이면 오류 메시지를 출력한 뒤 다시 읽으며, 범위 안이면 `break`로 `do-while`을 빠져나간다. 메뉴는 `char`이므로 숫자가 아니라 문자 `'1'`, `'5'`와 비교한다.
- **종료:** 메뉴가 `'5'`이면 종료 메시지를 출력하고 `break`로 바깥 `while`을 빠져나간다.
- **case 1 (왼쪽 정렬 삼각형):** i번째 줄에 별 i개를 출력한다.
- **case 2 (오른쪽 정렬 삼각형):** `j = size - i`부터 1까지 공백 size - i개를 출력한 뒤 별 i개를 출력한다.
- **case 3 (왼쪽 정렬 역삼각형):** `j = size - i`부터 0까지 반복하므로 별 size - i + 1개를 출력한다. 첫 줄은 size개, 마지막 줄은 1개이다.
- **case 4 (오른쪽 정렬 역삼각형):** `j = 1`부터 i까지 공백 i개를 출력한 뒤 별 size - i + 1개를 출력한다.

**코드:** [Lab_Q5.c](../../Coursework/Lab05_Control-Statements/Lab_Q5.c)

```c
/**
 * @file    A10104-2_C05Q2.c
 * @brief   Q2. 삼각형 출력 메뉴
 * @author  박철원 (Cheolwon Park)
 * @date    2024-04-10
 * 
 * @note    <windows.h> 헤더는 Windows 이외의 개발환경에서
 *          오류가 발생할 수 있음에 주의하시기 바랍니다.
 */

#pragma warning(disable:4996)
#include <stdio.h>
#include <windows.h>    // system 함수를 사용하기 위해 추가

int main()
{
    int size, i, j;
    char menu;

    while (1) {
        printf("-------------------------------\n");
        printf("1. 왼쪽 정렬 삼각형 출력\n");
        printf("2. 오른쪽 정렬 삼각형 출력\n");
        printf("3. 왼쪽 정렬 역삼각형 출력\n");
        printf("4. 오른쪽 정렬 역삼각형 출력\n");
        printf("5. 종료\n");
        printf("-------------------------------\n");

        do {
            printf("=> 메뉴 선택: ");
            scanf(" %c", &menu);
            if (menu < '1' || menu > '5')
                printf("입력 오류! 메뉴를 다시 선택하세요. \n");
            else
                break;
        } while (1);

        if (menu == '5') {
            printf("프로그램을 종료합니다. \n");
            break;
        }

        printf("=> 삼각형 크기(line 수) 입력: ");
        scanf(" %d", &size);

        switch (menu) {
        case '1':
            for (i = 1; i <= size; i++) {
                for (j = 1; j <= i; j++)
                    printf("*");
                printf("\n");
            }
            break;
        case '2':
            for (i = 1; i <= size; i++) {
                for (j = size - i; j >= 1; j--)
                    printf(" ");
                for (j = 1; j <= i; j++)
                    printf("*");
                printf("\n");
            }
            break;
        case '3':
            for (i = 1; i <= size; i++) {
                for (j = size - i; j >= 0; j--)
                    printf("*");
                printf("\n");
            }
            break;
        case '4':
            for (i = 1; i <= size; i++) {
                for (j = 1; j <= i; j++)
                    printf(" ");
                for (j = size - i; j >= 0; j--)
                    printf("*");
                printf("\n");
            }
            break;
        }

        system("pause");
        system("cls");
    }

    return 0;
}
```
