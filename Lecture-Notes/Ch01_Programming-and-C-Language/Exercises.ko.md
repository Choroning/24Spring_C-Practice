## 연습 문제 2: 프로그래밍 언어에 대한 설명

**교재 문항:** 1장 연습 문제 2번

**문제:** 프로그래밍 언어에 대한 다음 설명 중 잘못된 것을 모두 고르라.

- ① 기계어로 작성된 프로그램은 변환 없이 여러 종류의 CPU에서 실행될 수 있다.
- ② 0과 1로 된 명령어 대신 그것과 일대일로 대응하는 니모닉 기호를 쓰는 언어가 어셈블리어이다.
- ③ 어셈블리어를 이용하면 기계 독립적인 프로그램을 작성할 수 있다.
- ④ 고급 언어를 사용하면 CPU의 종류나 하드웨어의 특성에 얽매이지 않는 프로그램을 작성할 수 있다.
- ⑤ C, C++, Java, Python은 고급 언어이다.
- ⑥ 컴파일러는 고급 언어로 작성된 프로그램을 기계어로 번역한다.
- ⑦ 기계어와 어셈블리어는 고급 언어이다.

## 연습 문제 8: C 언어와 C++ 언어

**교재 문항:** 1장 연습 문제 8번

**문제:** C 언어와 C++ 언어에 대한 다음 설명 중 잘못된 것을 고르라.

- ① C 언어를 이어받아 객체지향성을 추가한 것이 C++ 언어이다.
- ② C 언어는 C++ 언어와의 호환성을 제공한다. 즉, 유효한 C++ 프로그램은 C 프로그램이다.
- ③ C로 작성된 프로그램을 C++로 바꾸는 간단한 방법은 소스 파일의 확장자를 `c`에서 `cpp`로 바꾸는 것이다.
- ④ 대부분의 C 컴파일러는 C/C++ 컴파일러이다.
- ⑤ C로 개발된 라이브러리를 C++ 프로그램에서 사용할 수 있다.

## 연습 문제 13: 사칙연산 결과를 출력하는 프로그램

**교재 문항:** 1장 프로그래밍 과제 2번

**문제:** Visual Studio에서 다음 조건으로 C 프로그램을 작성하고, 빌드한 뒤 실행하라.

1. 프로젝트 이름: `calculator`
2. 프로젝트 위치: `C:\work\chap01`
3. 프로젝트 유형: 빈 프로젝트(C++, Windows, 콘솔)
4. 소스 파일 이름: `calculator.c`
5. 소스 파일 내용:

```c
#include <stdio.h>

int main(void)
{
    printf("55 + 33 = %d\n", 55 + 33);
    printf("55 - 33 = %d\n", 55 - 33);
    printf("55 * 33 = %d\n", 55 * 33);
    printf("55 / 33 = %d\n", 55 / 33);

    return 0;
}
```

**실행 예시:**

```text
55 + 33 = 88
55 - 33 = 22
55 * 33 = 1815
55 / 33 = 1
```
