## 연습 문제 1: 주석에 대한 설명

**교재 문항:** 2장 연습 문제 1번

**문제:** 주석에 대한 일곱 가지 설명 중 잘못된 것을 모두 고르라. 보기는 [연습 문제 1](Exercises.ko.md#연습-문제-1-주석에-대한-설명)에 있다.

### 풀이

**정답:** ②, ⑦

**해설:** 주석은 소스 코드에 대한 정보를 제공하거나 소스 코드의 일부를 컴파일하지 않게 만들 때 쓰며, 컴파일러가 무시하고 사람이 읽기 위해 존재한다([2장 1.2절](Concepts_Lecture.ko.md#12-주석)). 따라서 주석은 컴파일되지 않고, 프로그램에 없어도 된다.

- **① (옳음):** 주석은 코드가 하는 일이나 작성 의도처럼 소스 코드에 대한 정보를 사람이 읽을 수 있게 적어 두는 설명이다.
- **② (잘못됨):** 주석은 컴파일러가 무시하므로 컴파일되지 않는다. 컴파일에 앞선 전처리 단계에서 각 주석이 빈칸 하나로 바뀌므로, 주석의 내용은 오브젝트 파일에 아무것도 남기지 않는다([1장 3.2절](../Ch01_Programming-and-C-Language/Concepts_Lecture.ko.md#32-빌드-과정)).
- **③ (옳음):** 블록 주석은 `/*`부터 `*/`까지이며 여러 줄에 걸칠 수 있다.
- **④ (옳음):** 줄 주석은 `//`부터 그 줄의 끝까지이다. C99에서 추가된 기능이며, 지금은 대부분의 C 컴파일러에서 쓸 수 있다.
- **⑤ (옳음):** 이미 작성한 코드를 지우지 않고 `/* */`로 감싸거나 줄 앞에 `//`를 붙이면 그 코드가 컴파일되지 않는다. 이를 코드 주석 처리(comment out)라고 한다.
- **⑥ (옳음):** 블록 주석은 중첩할 수 없다. `/* 외부 /* 내부 */ 나머지 */`에서는 처음 나온 `*/`가 주석을 닫으므로 `나머지 */`가 코드로 남아 컴파일 에러가 난다.
- **⑦ (잘못됨):** 주석은 컴파일 결과에 영향을 주지 않으므로 주석이 하나도 없는 프로그램도 정상적으로 컴파일되고 실행된다. 주석은 코드를 읽고 고치는 사람을 위해 쓰는 것이다.

## 연습 문제 2: 함수에 대한 설명

**교재 문항:** 2장 연습 문제 2번

**문제:** 함수의 구성과 실행 흐름에 대한 일곱 가지 설명 중 잘못된 것을 모두 고르라. 보기는 [연습 문제 2](Exercises.ko.md#연습-문제-2-함수에-대한-설명)에 있다.

### 풀이

**정답:** ⑤, ⑥

**해설:** 함수는 리턴형, 함수 이름, 매개변수로 구성된다. 함수가 호출되면 `{ }` 안의 문장들이 위에서부터 순서대로 수행되고, 함수의 끝(`}`)이나 `return`을 만나면 함수를 호출한 곳으로 되돌아간다([2장 1.3절](Concepts_Lecture.ko.md#13-main-함수)).

- **① (옳음):** 함수를 정의하려면 리턴형, 함수 이름, 매개변수의 세 요소가 필요하다. `int main(void)`에서는 각각 `int`, `main`, `void`이다.
- **② (옳음):** 매개변수가 없는 함수는 `int main(void)`처럼 `void`를 쓰거나 `int main()`처럼 괄호 안을 비워 둔다.
- **③ (옳음):** 함수가 처리할 문장들은 함수 본문인 중괄호 `{ }` 안에 쓴다.
- **④ (옳음):** 함수 안의 문장들은 위에서 아래로 하나씩 순서대로 수행된다. 이 흐름을 바꾸는 것은 5장의 조건문과 반복문이다([2장 3절](Concepts_Lecture.ko.md#3-c-문장)).
- **⑤ (잘못됨):** 함수의 끝(`}`)이나 `return`을 만나면 함수의 시작이 아니라 **함수를 호출한 곳**으로 되돌아간다. 이를 리턴이라고 하며, 호출한 쪽은 함수 호출 다음부터 실행을 이어 간다. 함수의 시작으로 되돌아간다면 함수가 끝나지 않고 같은 문장들을 되풀이하게 된다.
- **⑥ (잘못됨):** C의 문장은 마침표가 아니라 세미콜론(`;`)으로 끝난다. 다만 중괄호로 묶은 블록과 `if`, `for` 같은 제어문에는 끝에 세미콜론을 붙이지 않으며, `#include` 같은 전처리기 지시문도 세미콜론 없이 쓴다.
- **⑦ (옳음):** C 프로그램은 `main` 함수 하나, 또는 `main` 함수와 여러 함수로 구성된다.

> **참고:** **빈 괄호와 `void`.** 함수를 정의할 때 괄호를 비워 두면(`int main() { ... }`) 매개변수가 없는 함수가 되므로, 정의에서는 ②의 두 방법이 같은 함수를 만든다. 그러나 C99에서 정의가 아닌 선언에 `int f();`처럼 빈 괄호를 쓰면 매개변수가 없다는 뜻이 아니라 매개변수에 대한 정보를 주지 않는다는 뜻이 되어, 컴파일러가 함수 호출의 인자 개수와 형을 검사하지 못한다. 매개변수가 없음을 정확히 나타내려면 `void`를 쓴다. C23부터는 빈 괄호도 `void`와 같은 뜻이다.

## 연습 문제 3: 프로그램이 시작될 때 호출되는 함수

**교재 문항:** 2장 연습 문제 3번

**문제:** `main` 함수처럼 C 프로그램이 처음 시작될 때 호출되는 함수의 이름을 쓰라. 문제 전문은 [연습 문제 3](Exercises.ko.md#연습-문제-3-프로그램이-시작될-때-호출되는-함수)에 있다.

### 풀이

**정답:** 진입점 함수(entry point function)

**해설:** 진입점 함수는 C 프로그램이 처음 시작될 때 호출되기로 약속된 함수이며, C에서는 `main` 함수가 모든 프로그램의 진입점이다([2장 1.3절](Concepts_Lecture.ko.md#13-main-함수)). 운영체제가 컴파일된 프로그램을 실행하면 `main`의 첫 문장부터 실행이 시작되고, `main`이 리턴하면 프로그램이 종료된다. 그래서 모든 C 프로그램에는 `main` 함수가 하나만 있어야 하며, 다른 함수는 `main`에서 직접 또는 다른 함수를 거쳐 호출될 때만 실행된다.

## 연습 문제 4: `main` 함수에 대한 설명

**교재 문항:** 2장 연습 문제 4번

**문제:** `main` 함수의 리턴형, 개수, 이름, 종료 코드에 대한 여섯 가지 설명 중 올바른 것을 모두 고르라. 보기는 [연습 문제 4](Exercises.ko.md#연습-문제-4-main-함수에-대한-설명)에 있다.

### 풀이

**정답:** ①, ④, ⑤, ⑥

**해설:** `main` 함수는 프로그램마다 하나만 있는 진입점이며, `int`형의 종료 코드를 운영체제에 돌려준다([2장 1.3절](Concepts_Lecture.ko.md#13-main-함수), [1.4절](Concepts_Lecture.ko.md#14-종료-코드)).

- **① (옳음):** `main`의 리턴형은 `int`이며, 리턴 값은 프로그램의 종료 상태를 나타내는 종료 코드이다.
- **② (잘못됨):** 모든 C 프로그램에는 `main` 함수가 하나만 있어야 한다. `main`이 없으면 컴파일은 되지만 링크 단계에서 진입점을 찾지 못해 실행 파일이 만들어지지 않는다. macOS의 clang은 이때 "Undefined symbols for architecture arm64" 에러와 함께 찾지 못한 기호 `_main`을 보고한다. 반대로 `main`이 둘 이상이면 같은 이름의 함수가 두 번 정의되어 에러가 난다.
- **③ (잘못됨):** C는 대소문자를 구분하므로 `main`, `Main`, `MAIN`은 서로 다른 식별자이다. 진입점으로 인식되는 것은 소문자 `main`뿐이며, `Main`만 정의한 프로그램은 ②와 같은 링크 에러를 낸다.
- **④ (옳음):** C99부터는 `main` 함수가 `return` 문 없이 끝(`}`)에 도달하면 0을 리턴한 것과 같다. 이 예외는 `main`에만 적용되며, 명확성을 위해 `return 0;`을 쓰는 것이 좋다.
- **⑤ (옳음):** 프로그램이 시작되면 운영체제가 `main`을 호출하여 실행이 시작된다(연습 문제 3).
- **⑥ (옳음):** 종료 코드 0은 정상 종료를, 0이 아닌 값은 비정상 종료를 뜻하며, 운영체제나 호출한 스크립트가 이 값으로 프로그램의 성공 여부를 판단한다.

> **참고:** **`main`을 호출하는 주체와 종료 코드.** 교재는 운영체제가 `main`을 호출한다고 설명한다. 정확히는 운영체제가 프로그램을 메모리에 적재한 뒤 실행 파일에 링크된 C 런타임의 시작 코드(startup code)로 제어를 넘기고, 이 시작 코드가 초기화를 마친 뒤 `main`을 호출한다. `main`이 리턴하면 시작 코드가 그 리턴 값으로 `exit` 함수를 호출하여 종료 코드를 운영체제에 전달한다. 또 C 표준이 의미를 정한 종료 코드는 성공을 뜻하는 0과 `EXIT_SUCCESS`, 실패를 뜻하는 `EXIT_FAILURE`(두 매크로는 `<stdlib.h>`에 있다)이며, 그 밖의 0이 아닌 값이 무엇을 뜻하는지는 운영체제와 프로그램이 정한다.

## 연습 문제 5: 변수에 대한 설명

**교재 문항:** 2장 연습 문제 5번

**문제:** 변수의 저장 공간, 대입, 선언, 이름에 대한 일곱 가지 설명 중 잘못된 것을 모두 고르라. 보기는 [연습 문제 5](Exercises.ko.md#연습-문제-5-변수에-대한-설명)에 있다.

### 풀이

**정답:** ④, ⑥

**해설:** 변수는 값을 저장하기 위한 공간이며, 메모리 공간에 이름을 붙여 주소 대신 이름으로 접근하게 해 준다. 변수는 사용하기 전에 데이터형과 이름을 지정하여 선언해야 한다([2장 2.4절](Concepts_Lecture.ko.md#24-입출력에서의-변수-활용)).

- **① (옳음):** 변수는 값을 저장하기 위한 공간이다.
- **② (옳음):** 변수를 선언하면 데이터형의 크기만큼 메모리 공간이 할당되고 그 공간에 변수 이름이 붙는다. 프로그램은 메모리 주소 대신 변수 이름으로 그 공간에 접근한다.
- **③ (옳음):** 대입 연산자 `=`는 오른쪽의 값을 왼쪽에 적힌 변수의 메모리 공간에 저장한다(`count = 5;`). 수학의 등호와 달리 두 값이 같다는 뜻이 아니다.
- **④ (잘못됨):** 변수를 선언할 때는 데이터형을 반드시 써야 한다. 데이터형이 있어야 컴파일러가 할당할 메모리의 크기와 저장된 값의 의미를 정할 수 있다(⑤).
- **⑤ (옳음):** 데이터형이 메모리 공간의 크기를 결정한다. `char`는 1바이트, `int`와 `float`는 대개 4바이트, `double`은 8바이트이다([3장 1절](../Ch03_Data-Types-and-Variables/Concepts_Lecture.ko.md#1-데이터-타입)).
- **⑥ (잘못됨):** 변수는 사용하기 전에 선언해야 한다. 선언하지 않은 변수에 `total = 5;`처럼 값을 대입하면 컴파일러가 `total`이라는 이름을 알지 못하므로 clang은 "use of undeclared identifier 'total'" 컴파일 에러를 낸다.
- **⑦ (옳음):** 변수 이름은 프로그래머가 만들어 쓰는 이름인 식별자이며, 영문자, 숫자, 밑줄로 만들고 첫 글자는 영문자나 밑줄이어야 한다는 식별자 규칙을 따른다([3장 3.2절](../Ch03_Data-Types-and-Variables/Concepts_Lecture.ko.md#32-식별자와-이름-규칙)).

> **참고:** **묵시적 `int`.** C89에서는 `static count = 3;`처럼 데이터형 없이 `static` 같은 키워드만 쓴 선언을 `int`형 변수의 선언으로 간주했다(implicit int). C99는 이 규칙을 없앴으므로 데이터형은 생략할 수 없다. macOS의 clang에서 `-std=c99`로 이 선언을 컴파일하면 "type specifier missing, defaults to 'int'; ISO C99 and later do not support implicit int" 에러가 나고, `-std=c89`에서는 같은 내용의 경고만 난다.

## 연습 문제 6: `printf`의 형식 지정자와 의미

**교재 문항:** 2장 연습 문제 6번

**문제:** `printf`의 형식 지정자 `%d`, `%f`, `%c`, `%x`, `%e`를 그 의미와 연결하라. 보기는 [연습 문제 6](Exercises.ko.md#연습-문제-6-printf의-형식-지정자와-의미)에 있다.

### 풀이

**정답:** (1) ②, (2) ③, (3) ⑤, (4) ①, (5) ④

**해설:** 형식 지정자는 `%`와 약속된 문자로 이루어진 자리표시자이며, `printf`는 대응하는 값을 그 형식으로 바꾸어 형식 지정자의 자리에 출력한다([2장 2.2절](Concepts_Lecture.ko.md#22-printf)).

| 형식 지정자 | 의미 | 예 | 출력 |
|:-----:|:-----|:-----|:-----|
| `%d` | ② 정수를 10진수로 출력 | `printf("%d", 255);` | `255` |
| `%f` | ③ 실수를 부동소수점 표기로 출력 | `printf("%f", 3.14);` | `3.140000` |
| `%c` | ⑤ 문자를 출력 | `printf("%c", 'A');` | `A` |
| `%x` | ① 정수를 16진수로 출력 | `printf("%x", 255);` | `ff` |
| `%e` | ④ 실수를 지수 표기로 출력 | `printf("%e", 3.14);` | `3.140000e+00` |

*표 1. `printf` 형식 지정자의 의미와 출력 예*

- **`%d`와 `%x`:** 둘 다 정수를 출력하며 진법만 다르다. 255는 10진수로 `255`, 16진수로 `ff`이다. `%X`를 쓰면 `FF`처럼 대문자로 출력된다.
- **`%f`와 `%e`:** 둘 다 `float`와 `double` 값을 출력한다. `%f`는 `3.140000`처럼 지수 없이 소수점 이하 6자리까지 쓰는 표기이고, `%e`는 `3.140000e+00`처럼 가수와 10의 지수로 쓰는 표기이다. `e+00`은 $\times 10^{0}$을 뜻한다.
- **`%c`:** 문자 코드에 해당하는 문자 하나를 출력한다. 같은 `'A'`를 `%d`로 출력하면 그 ASCII 코드인 `65`가 출력된다([3장 1.3절](../Ch03_Data-Types-and-Variables/Concepts_Lecture.ko.md#13-문자형)).

## 연습 문제 7: 실행 결과에 맞는 형식 지정자

**교재 문항:** 2장 연습 문제 7번

**문제:** `float pi = 3.141592;`를 출력하여 `pi = 3.14`가 나오도록 `printf`의 빈칸을 채우라. 문제 전문과 소스 코드는 [연습 문제 7](Exercises.ko.md#연습-문제-7-실행-결과에-맞는-형식-지정자)에 있다.

### 풀이

**정답:** `%.2f`

**해설:** 실행 결과 `3.14`는 `pi`의 값을 소수점 이하 2자리까지 출력한 것이므로, 정밀도를 2로 지정한 `%.2f`를 쓴다([2장 2.2절](Concepts_Lecture.ko.md#22-printf)).

- **변환 문자 `f`:** `pi`는 `float`형 변수이다. `float` 값은 `printf`에 인자로 넘겨질 때 `double`로 자동 변환되므로 `float`와 `double`을 모두 `%f`로 출력한다.
- **정밀도 `.2`:** `%`와 `f` 사이에 `.2`를 쓰면 소수점 이하 셋째 자리에서 반올림하여 둘째 자리까지 출력한다. 3.141592는 `3.14`가 된다. 정밀도를 지정하지 않은 `%f`는 `3.141592`처럼 소수점 이하 6자리를 출력한다.
- **문자 폭:** `%4.2f`처럼 문자 폭을 함께 지정해도 `3.14`가 4글자이므로 결과가 같다. 문자 폭이 더 크면 `%6.2f`가 `  3.14`처럼 앞을 빈칸으로 채운다.

빈칸을 채운 프로그램은 다음과 같다. 이 코드에는 `return` 문이 없지만 C99부터 `main`은 끝에 도달하면 0을 리턴하므로 정상 종료된다(연습 문제 4의 ④).

**코드:**

```c
#include <stdio.h>

int main(void)
{
    float pi = 3.141592;
    printf("pi = %.2f\n", pi);
}
```

**실행 결과:**

```text
pi = 3.14
```

## 연습 문제 8: 변수 선언에 필요한 두 가지

**교재 문항:** 2장 연습 문제 8번

**문제:** 변수를 선언할 때 필요한 두 가지를 쓰라. 문제 전문은 [연습 문제 8](Exercises.ko.md#연습-문제-8-변수-선언에-필요한-두-가지)에 있다.

### 풀이

**정답:** 데이터형과 변수 이름

**해설:** 선언은 컴파일러에게 변수의 데이터형과 이름을 알려 주는 것이다([2장 2.4절](Concepts_Lecture.ko.md#24-입출력에서의-변수-활용)). `int count;`에서 `int`가 데이터형이고 `count`가 변수 이름이다.

- **데이터형:** 변수에 저장할 데이터의 종류이며, 할당할 메모리 공간의 크기와 저장된 값의 의미를 결정한다. `int`는 정수, `double`은 실수, `char`는 문자를 저장한다.
- **변수 이름:** 변수를 구분하는 식별자이며, 프로그램은 이 이름으로 변수의 메모리 공간에 접근한다.

초기값은 선언에 반드시 필요한 것이 아니며, `int count = 5;`처럼 선언과 함께 지정하면 초기화가 된다. 같은 데이터형의 변수 여러 개는 `int a, b, c;`처럼 쉼표로 이어서 한 번에 선언할 수 있다([3장 3.1절](../Ch03_Data-Types-and-Variables/Concepts_Lecture.ko.md#31-선언과-초기화)).

## 연습 문제 9: 입출력 라이브러리 헤더

**교재 문항:** 2장 연습 문제 9번

**문제:** `scanf`와 `printf`를 사용하기 위해 필요한 입출력 라이브러리 헤더를 쓰라. 문제 전문은 [연습 문제 9](Exercises.ko.md#연습-문제-9-입출력-라이브러리-헤더)에 있다.

### 풀이

**정답:** `<stdio.h>`

**해설:** C에는 입출력 키워드가 내장되어 있지 않고, 입출력 라이브러리가 `printf`, `scanf` 같은 입출력 함수를 제공한다. 이 함수들의 선언은 표준 입출력(standard input/output) 헤더 파일인 `stdio.h`에 들어 있으므로, 소스 파일 앞에 `#include <stdio.h>`를 써서 포함한다([2장 2.1절](Concepts_Lecture.ko.md#21-콘솔-입출력)).

- **헤더 파일의 역할:** 헤더 파일에는 함수 이름, 리턴형, 매개변수 같은 함수 선언이 들어 있다. 전처리기가 `#include`를 만나면 헤더 파일의 내용을 그 자리에 복사하고, 컴파일러는 이 선언을 보고 `printf`와 `scanf`의 호출이 올바른지 검사한다.
- **함수의 정의:** 헤더 파일에는 선언만 있고, 함수를 실제로 수행하는 코드는 표준 라이브러리에 들어 있어 링크 단계에서 실행 파일에 연결된다([1장 3.2절](../Ch01_Programming-and-C-Language/Concepts_Lecture.ko.md#32-빌드-과정)).
- **헤더가 없을 때:** `#include <stdio.h>`를 빠뜨리면 컴파일러가 `printf`와 `scanf`의 선언을 알 수 없어 에러나 경고가 발생한다.

## 연습 문제 10: 문자를 입력받아 출력하는 프로그램

**교재 문항:** 2장 연습 문제 10번

**문제:** 문자 하나를 `scanf`로 입력받아 `printf`로 출력하는 프로그램의 빈칸 ①, ②, ③을 채우라. 문제 전문과 소스 코드는 [연습 문제 10](Exercises.ko.md#연습-문제-10-문자를-입력받아-출력하는-프로그램)에 있다.

### 풀이

**정답:** ① `<stdio.h>`, ② `&ch`, ③ `%c`

**해설:** `scanf`와 `printf`를 쓰려면 표준 입출력 헤더를 포함해야 하고, `scanf`에는 변수의 주소를 넘기며, `char`형 값은 `%c`로 출력한다([2장 2.3절](Concepts_Lecture.ko.md#23-scanf)).

- **① `<stdio.h>`:** `scanf`와 `printf`의 선언이 들어 있는 표준 입출력 헤더이다(연습 문제 9). 그 앞의 `#define _CRT_SECURE_NO_WARNINGS`는 Visual Studio가 `scanf`를 안전하지 않은 함수로 보고 내는 에러(C4996)를 막는 매크로이며, `#include`보다 앞에 써야 효과가 있다.
- **② `&ch`:** `scanf`는 입력받은 값을 저장할 메모리 주소가 필요하므로 변수 이름 앞에 주소 연산자 `&`를 붙인다. `&` 없이 `ch`를 넘기면 주소가 아니라 `ch`의 값(초기화되지 않은 쓰레기 값)이 넘어가 정의되지 않은 동작이 발생하며, clang은 `-Wall`에서 "format specifies type 'char *' but the argument has type 'int'" 경고를 낸다.
- **③ `%c`:** `char`형 변수에 저장된 문자 하나를 출력하는 형식 지정자이다. 여기에 `%d`를 쓰면 문자 대신 그 문자의 코드(`A`이면 65)가 출력된다.

빈칸을 채운 프로그램은 다음과 같다. `A`를 입력하면 `ch = A`가 출력된다. 이 프로그램은 입력 안내 문구를 출력하지 않으므로 실행하면 빈 줄에서 입력을 기다린다.

**코드:**

```c
// test.c
#define _CRT_SECURE_NO_WARNINGS     // Visual Studio 2022에서 scanf 사용 시 필요
#include <stdio.h>

int main(void)
{
    char ch;
    scanf("%c", &ch);
    printf("ch = %c\n", ch);
}
```

**실행 결과:**

```text
A
ch = A
```

## 연습 문제 11: `printf` 한 번으로 여러 줄 출력

**교재 문항:** 2장 프로그래밍 과제 1번

**문제:** `printf` 문을 한 번만 사용하여 `int main(void)`, `{`, `return 0;`(앞에 빈칸 네 개), `}`의 네 줄을 출력하라. 문제 전문과 실행 예시는 [연습 문제 11](Exercises.ko.md#연습-문제-11-printf-한-번으로-여러-줄-출력)에 있다.

### 풀이

**접근 방법:** `printf`는 자동으로 줄을 바꾸지 않으므로, 네 줄을 문자열 하나에 담고 줄이 바뀌는 자리마다 줄바꿈 이스케이프 시퀀스 `\n`을 넣는다([2장 2.2절](Concepts_Lecture.ko.md#22-printf)).

- **줄바꿈:** `"int main(void)\n{\n    return 0;\n}\n"`에는 `\n`이 네 번 나오므로 네 줄이 출력되고, 마지막 `\n` 때문에 커서가 다음 줄의 처음으로 이동한다.
- **들여쓰기:** `return 0;` 앞의 빈칸 네 개는 문자열 안에 그대로 쓴다. 탭 문자 `\t`를 쓰면 콘솔에서 대개 8칸 너비로 표시되어 실행 예시와 달라진다.
- **출력할 글자와 실행할 문장:** 큰따옴표 안의 `return 0;`은 출력할 글자일 뿐 실행되는 문장이 아니다. 프로그램을 실제로 끝내는 것은 `printf` 다음 줄의 `return 0;`이다.

**코드:**

```c
#include <stdio.h>

int main(void)
{
    // One printf call prints all four lines; \n ends each line
    printf("int main(void)\n{\n    return 0;\n}\n");

    return 0;
}
```

**실행 결과:**

```text
int main(void)
{
    return 0;
}
```

> **참고:** **문자열 리터럴의 연결.** 공백이나 줄바꿈만을 사이에 두고 이어진 문자열 리터럴은 컴파일할 때 하나의 문자열로 합쳐진다. 따라서 다음처럼 출력할 줄마다 문자열을 나누어 써도 `printf`를 한 번 호출하는 것이며, 출력도 같다.

```c
printf("int main(void)\n"
       "{\n"
       "    return 0;\n"
       "}\n");
```

## 연습 문제 12: 10진수 정수를 16진수로 출력

**교재 문항:** 2장 프로그래밍 과제 2번

**문제:** 10진수 정수를 입력받아 16진수로 출력하라. 문제 전문과 실행 예시는 [연습 문제 12](Exercises.ko.md#연습-문제-12-10진수-정수를-16진수로-출력)에 있다.

### 풀이

**접근 방법:** 정수는 메모리에 2진수로 저장되며, 10진수와 16진수는 같은 값을 글자로 나타내는 방법의 차이이다([3장 2.1절](../Ch03_Data-Types-and-Variables/Concepts_Lecture.ko.md#21-진법)). 따라서 값을 한 번 입력받아 변수 하나에 저장하고, 출력할 때 같은 변수를 `%d`와 `%x`로 두 번 출력한다([2장 2.2절](Concepts_Lecture.ko.md#22-printf)).

- **입력:** `scanf("%d", &num);`은 키보드로 입력한 글자 `10`을 10진수로 해석하여 정수 10을 `num`에 저장한다.
- **출력:** 형식 문자열의 `%d`와 `%x`에 각각 `num`을 대응시킨다. 10은 16진수 한 자리 `a`이다. 16진수를 대문자로 출력하려면 `%X`를 쓴다.

**코드:**

```c
#define _CRT_SECURE_NO_WARNINGS  // allows scanf in Visual Studio
#include <stdio.h>

int main(void)
{
    int num;

    printf("10진수 정수? ");
    scanf("%d", &num);                    // read a decimal integer

    // %d prints the value in decimal, %x prints the same value in hexadecimal
    printf("10진수 %d은 16진수 %x에 해당합니다.\n", num, num);

    return 0;
}
```

**실행 결과:** 171을 입력하면 171 = 16 × 10 + 11이므로 두 자리 16진수 `ab`가 출력된다.

```text
10진수 정수? 10
10진수 10은 16진수 a에 해당합니다.
```

```text
10진수 정수? 171
10진수 171은 16진수 ab에 해당합니다.
```

> **주의:** **음수 입력.** `%x`는 `unsigned int` 값을 기대하므로, 음수를 입력하면 그 비트 패턴을 부호 없는 정수로 해석한 값이 출력된다. 32비트 `int`에서 -1은 2의 보수로 모든 비트가 1이므로 `ffffffff`가 출력된다([3장 2.2절](../Ch03_Data-Types-and-Variables/Concepts_Lecture.ko.md#22-정수의-2진-표현-2의-보수)).

```text
10진수 정수? -1
10진수 -1은 16진수 ffffffff에 해당합니다.
```

## 연습 문제 13: 날짜의 입력과 출력

**교재 문항:** 2장 프로그래밍 과제 3번

**문제:** 연, 월, 일을 각각 정수로 입력받아 날짜를 출력하라. 문제 전문과 실행 예시는 [연습 문제 13](Exercises.ko.md#연습-문제-13-날짜의-입력과-출력)에 있다.

### 풀이

**접근 방법:** 연, 월, 일을 저장할 `int`형 변수 세 개를 선언하고, 값을 하나 입력받기 전마다 `연? ` 같은 안내 문구를 출력한다. 안내 문구에 `\n`이 없으므로 커서가 물음표 뒤에 남아 그 자리에서 값을 입력하게 된다([2장 2.3절](Concepts_Lecture.ko.md#23-scanf)).

- **입력:** `scanf("%d", &year);`처럼 변수마다 `&`를 붙여 주소를 넘긴다. 세 값을 `scanf("%d %d %d", &year, &month, &day);` 한 번으로 읽을 수도 있지만, 실행 예시처럼 값마다 안내 문구를 출력하려면 입력을 세 번으로 나눈다.
- **출력:** 형식 지정자 세 개와 변수 세 개가 순서대로 대응한다. 실행 예시에 맞추어 `일` 뒤에 빈칸을 하나 두고 `입니다.`를 출력한다.

**코드:**

```c
#define _CRT_SECURE_NO_WARNINGS  // allows scanf in Visual Studio
#include <stdio.h>

int main(void)
{
    int year, month, day;

    printf("연? ");
    scanf("%d", &year);
    printf("월? ");
    scanf("%d", &month);
    printf("일? ");
    scanf("%d", &day);

    printf("입력한 날짜는 %d년 %d월 %d일 입니다.\n", year, month, day);

    return 0;
}
```

**실행 결과:**

```text
연? 2022
월? 10
일? 1
입력한 날짜는 2022년 10월 1일 입니다.
```

> **주의:** **입력 값의 검사.** 이 프로그램은 정수를 입력받아 출력할 뿐, 입력받은 값이 유효한 날짜인지 검사하지 않는다. 연, 월, 일에 각각 -500, 15, 55를 입력하면 "-500년 15월 55일"이 그대로 출력된다. 월이 1~12인지, 일이 그 달의 날수 안에 있는지 검사하려면 [5장 2절](../Ch05_Control-Statements/Concepts_Lecture.ko.md#2-조건문)의 조건문이 필요하다.

```text
연? -500
월? 15
일? 55
입력한 날짜는 -500년 15월 55일 입니다.
```

## 연습 문제 14: 시, 분, 초를 두 자리로 출력

**교재 문항:** 2장 프로그래밍 과제 4번

**문제:** 시, 분, 초를 입력받아 1시 1분 1초를 "01:01:01"처럼 두 자리씩 출력하라. 문제 전문과 실행 예시는 [연습 문제 14](Exercises.ko.md#연습-문제-14-시-분-초를-두-자리로-출력)에 있다.

### 풀이

**접근 방법:** 입력은 연습 문제 13과 같이 하고, 출력할 때 각 값을 두 자리로 맞춘다. 문자 폭을 2로 지정한 `%2d`는 한 자리 수 앞을 빈칸으로 채우고, 문자 폭 앞에 `0`을 쓴 `%02d`는 빈칸 대신 0을 채운다([3장 5.2절](../Ch03_Data-Types-and-Variables/Concepts_Lecture.ko.md#52-출력-폭과-정렬)).

| 값 | `%d` | `%2d` | `%02d` |
|:---:|:---:|:---:|:---:|
| 1 | `1` | `␣1` | `01` |
| 13 | `13` | `13` | `13` |

*표 2. 문자 폭과 0 채움에 따른 출력 (␣는 빈칸)*

- **`%02d`:** 1은 `01`로, 13은 그대로 `13`으로 출력된다.
- **구분자:** 형식 문자열 `"%02d:%02d:%02d"`의 콜론은 일반 문자이므로 그대로 출력된다.

**코드:**

```c
#define _CRT_SECURE_NO_WARNINGS  // allows scanf in Visual Studio
#include <stdio.h>

int main(void)
{
    int hour, minute, second;

    printf("시? ");
    scanf("%d", &hour);
    printf("분? ");
    scanf("%d", &minute);
    printf("초? ");
    scanf("%d", &second);

    // %02d: width 2, empty positions filled with 0
    printf("입력한 시간은 %02d:%02d:%02d입니다.\n", hour, minute, second);

    return 0;
}
```

**실행 결과:** 13, 5, 9를 입력하면 한 자리 수인 분과 초에만 0이 채워진다.

```text
시? 1
분? 1
초? 1
입력한 시간은 01:01:01입니다.
```

```text
시? 13
분? 5
초? 9
입력한 시간은 13:05:09입니다.
```

> **주의:** **문자 폭은 최소 폭이다.** 값이 두 자리를 넘으면 잘리지 않고 모두 출력되며, 음수는 부호가 한 글자를 차지한다. 100, -5, 7을 입력하면 "100:-5:07"이 출력된다. 이 프로그램도 시가 0\~23, 분과 초가 0\~59의 범위에 있는지 검사하지 않는다.

```text
시? 100
분? -5
초? 7
입력한 시간은 100:-5:07입니다.
```

문자 폭, 정렬, 0 채움을 함께 연습하는 문제는 [HW01 Q3](../../Coursework/HW01_Data-Types-and-Variables/Assignment-Explanation.ko.md#33-q3-변수-연습-3)에 있다.

## 연습 문제 15: 달러를 원화로 환산

**교재 문항:** 2장 프로그래밍 과제 5번

**문제:** 달러를 실수로 입력받아 1달러를 1000원으로 환산한 원화를 정수로 출력하라. 문제 전문과 실행 예시는 [연습 문제 15](Exercises.ko.md#연습-문제-15-달러를-원화로-환산)에 있다.

### 풀이

**접근 방법:** 달러는 소수점이 있는 실수이므로 `double`형 변수에 `%lf`로 입력받고, 원화는 `int`형 변수에 저장하여 `%d`로 출력한다([2장 2.3절](Concepts_Lecture.ko.md#23-scanf)).

- **환율 상수:** 1달러가 1000원이라는 값은 `#define WON_PER_DOLLAR 1000`으로 이름을 붙여 둔다. 환율이 바뀌면 이 줄만 고치면 된다([3장 4.2절](../Ch03_Data-Types-and-Variables/Concepts_Lecture.ko.md#42-매크로-상수-define)).
- **입력:** `scanf`에서 `double`은 `%f`가 아니라 `%lf`로 읽는다.
- **실수를 정수로:** `dollars * WON_PER_DOLLAR`는 `double`형 값이다. 실수를 `int`로 바꾸면 소수 부분이 버려지므로, 0.5를 더한 뒤 `(int)`로 형 변환하여 가장 가까운 정수로 반올림한다([3장 6.2절](../Ch03_Data-Types-and-Variables/Concepts_Lecture.ko.md#62-명시적-형-변환-캐스팅)). 이 반올림은 금액이 음수가 아닐 때 성립하며, 반올림이 필요한 이유는 아래의 주의 상자에 있다.
- **출력:** 달러는 센트 단위까지 보이도록 `%.2f`로, 원화는 `%d`로 출력한다. 형식 문자열의 `$`는 일반 문자이다.

**코드:**

```c
#define _CRT_SECURE_NO_WARNINGS  // allows scanf in Visual Studio
#include <stdio.h>

#define WON_PER_DOLLAR 1000      // exchange rate: 1 dollar = 1000 won

int main(void)
{
    double dollars;
    int won;

    printf("달러? ");
    scanf("%lf", &dollars);              // %lf reads a double

    // add 0.5 before truncating to int so that 2009.9999... becomes 2010
    won = (int)(dollars * WON_PER_DOLLAR + 0.5);

    printf("$%.2f는 %d원입니다.\n", dollars, won);

    return 0;
}
```

**실행 결과:** 50.25 × 1000 = 50250원이 출력된다. 2.01달러도 2010원으로 바르게 환산된다.

```text
달러? 50.25
$50.25는 50250원입니다.
```

```text
달러? 2.01
$2.01는 2010원입니다.
```

> **주의:** **실수의 표현 오차와 소수 부분의 버림.** 반올림 없이 `won = dollars * WON_PER_DOLLAR;`로 대입하면 결과가 1원 모자랄 수 있다. 2.01은 2진수로 정확히 나타낼 수 없어 `double`에 2.00999999999999978684...로 저장되고, 여기에 1000을 곱한 2009.9999999999998이 `int`로 변환되면서 소수 부분이 버려져 2009가 되기 때문이다([3장 1.2절](../Ch03_Data-Types-and-Variables/Concepts_Lecture.ko.md#12-실수형)). 다음은 반올림 없이 대입한 프로그램에 2.01을 입력한 결과이다.

```text
달러? 2.01
$2.01는 2009원입니다.
```

## 연습 문제 16: 옷 사이즈의 선택

**교재 문항:** 2장 프로그래밍 과제 6번

**문제:** 옷 사이즈를 S, M, L 중 한 문자로 입력받아 선택된 사이즈를 출력하라. 문제 전문과 실행 예시는 [연습 문제 16](Exercises.ko.md#연습-문제-16-옷-사이즈의-선택)에 있다.

### 풀이

**접근 방법:** 문자 하나는 `char`형 변수에 저장하며, 입력과 출력 모두 형식 지정자 `%c`를 쓴다([2장 2.3절](Concepts_Lecture.ko.md#23-scanf)).

- **입력:** `scanf(" %c", &size);`에서 `%c` 앞의 빈칸은 입력의 빈칸, 탭, 줄바꿈 같은 공백 문자를 모두 건너뛰게 한다. `%c`는 숫자 형식 지정자와 달리 공백 문자를 건너뛰지 않으므로, 이 빈칸이 없으면 사용자가 `M` 앞에 빈칸을 입력했을 때 빈칸이 저장된다.
- **출력:** `%c` 자리에 `size`에 저장된 문자가 출력되고, 뒤에 ` 사이즈를 선택했습니다.`가 이어진다.

**코드:**

```c
#define _CRT_SECURE_NO_WARNINGS  // allows scanf in Visual Studio
#include <stdio.h>

int main(void)
{
    char size;

    printf("옷 사이즈(S,M,L)? ");
    scanf(" %c", &size);                 // the space skips leading whitespace

    printf("%c 사이즈를 선택했습니다.\n", size);

    return 0;
}
```

**실행 결과:**

```text
옷 사이즈(S,M,L)? M
M 사이즈를 선택했습니다.
```

> **주의:** **문자 하나만 읽는다.** `%c`는 문자 하나만 읽으므로 `XL`을 입력하면 `X`만 저장되고 `L`은 입력 버퍼에 남는다. 또 입력이 S, M, L 중 하나인지 검사하지 않으므로 소문자나 다른 문자도 그대로 출력된다. 입력을 S, M, L로 제한하려면 [5장 2절](../Ch05_Control-Statements/Concepts_Lecture.ko.md#2-조건문)의 조건문이 필요하다.

```text
옷 사이즈(S,M,L)? XL
X 사이즈를 선택했습니다.
```

## 연습 문제 17: 두 실수의 합과 차

**교재 문항:** 2장 프로그래밍 과제 7번

**문제:** 실수 2개를 입력받아 합과 차를 출력하라. 문제 전문과 실행 예시는 [연습 문제 17](Exercises.ko.md#연습-문제-17-두-실수의-합과-차)에 있다.

### 풀이

**접근 방법:** 두 실수를 `double`형 변수에 입력받고, 합과 차는 `printf`의 인자 자리에서 `x + y`, `x - y`로 바로 계산한다([2장 2.3절](Concepts_Lecture.ko.md#23-scanf)).

- **입력:** `scanf("%lf %lf", &x, &y);`는 공백 문자로 구분된 두 실수를 차례로 읽는다. `12.34 0.5`처럼 한 줄에 빈칸을 두고 입력해도 되고, 두 줄로 나누어 입력해도 된다.
- **출력:** 실행 예시의 `12.340000`은 정밀도를 지정하지 않은 `%f`가 소수점 이하 6자리를 출력한 것이다. 한 줄에 형식 지정자가 세 개이므로 `x`, `y`, 계산 결과를 순서대로 넘긴다.
- **`%lf`와 `%f`:** `double`은 `scanf`에서 `%lf`로 읽고 `printf`에서 `%f`로 출력한다.

**코드:**

```c
#define _CRT_SECURE_NO_WARNINGS  // allows scanf in Visual Studio
#include <stdio.h>

int main(void)
{
    double x, y;

    printf("실수 2개? ");
    scanf("%lf %lf", &x, &y);            // %lf for double in scanf

    printf("%f + %f = %f\n", x, y, x + y);   // %f for double in printf
    printf("%f - %f = %f\n", x, y, x - y);

    return 0;
}
```

**실행 결과:**

```text
실수 2개? 12.34 0.5
12.340000 + 0.500000 = 12.840000
12.340000 - 0.500000 = 11.840000
```

> **주의:** **`scanf`에서 `double`을 `%f`로 읽는 실수.** `scanf("%f %f", &x, &y);`로 쓰면 `scanf`가 `double` 변수의 메모리에 `float` 형식의 값을 저장하므로 정의되지 않은 동작이 발생한다. `-Wall`로 컴파일하면 clang이 "format specifies type 'float *' but the argument has type 'double *'" 경고를 내며, 이 환경에서 실행하면 다음처럼 입력과 무관한 값이 출력된다.

```text
실수 2개? 12.34 0.5
0.000000 + 0.000000 = 0.000000
0.000000 - 0.000000 = 0.000000
```

## 연습 문제 18: 원주율을 여러 형식으로 출력

**교재 문항:** 2장 프로그래밍 과제 8번

**문제:** 원주율 3.14159265를 소수점 이하 2, 4, 6, 8자리와 지수 표기로 출력하고, `float`형 변수와 `double`형 변수에 저장한 경우를 비교하라. 문제 전문과 실행 예시는 [연습 문제 18](Exercises.ko.md#연습-문제-18-원주율을-여러-형식으로-출력)에 있다.

### 풀이

**접근 방법:** 같은 값을 정밀도만 바꾸어 다섯 번 출력한다. 정밀도는 `%`와 `f` 사이에 `.`과 정수로 지정하며, 지정한 자리의 다음 자리에서 반올림된다([2장 2.2절](Concepts_Lecture.ko.md#22-printf)).

| 형식 지정자 | 의미 | 출력 |
|:-----:|:-----|:-----|
| `%.2f` | 소수점 이하 2자리 | `3.14` |
| `%.4f` | 소수점 이하 4자리 | `3.1416` |
| `%f` | 소수점 이하 6자리 (기본값) | `3.141593` |
| `%.8f` | 소수점 이하 8자리 | `3.14159265` |
| `%e` | 지수 표기 (가수의 소수점 이하 6자리) | `3.141593e+00` |

*표 3. 원주율의 출력에 쓰는 형식 지정자*

- **반올림:** 3.14159265를 소수점 이하 4자리로 나타내면 다섯째 자리의 9에서 올림되어 `3.1416`이 되고, 6자리로 나타내면 일곱째 자리의 6에서 올림되어 `3.141593`이 된다.
- **지수 표기:** `3.141593e+00`은 $3.141593 \times 10^{0}$이다.

**코드:**

```c
#include <stdio.h>

int main(void)
{
    double pi = 3.14159265;

    printf("pi = %.2f\n", pi);           // 2 digits after the decimal point
    printf("pi = %.4f\n", pi);           // 4 digits
    printf("pi = %f\n", pi);             // default precision: 6 digits
    printf("pi = %.8f\n", pi);           // 8 digits
    printf("pi = %e\n", pi);             // exponential notation

    return 0;
}
```

**실행 결과:**

```text
pi = 3.14
pi = 3.1416
pi = 3.141593
pi = 3.14159265
pi = 3.141593e+00
```

**`float`와 `double`의 비교:** 파이값을 `float`형 변수에 저장하면 소수점 이하 8자리의 출력이 달라진다. `float`의 유효숫자는 약 7자리이고 `double`의 유효숫자는 약 15자리이기 때문이다([3장 1.2절](../Ch03_Data-Types-and-Variables/Concepts_Lecture.ko.md#12-실수형)). 3.14159265에 가장 가까운 `float` 값은 3.14159274101257324...이므로 `%.8f`는 `3.14159274`를 출력하고, `double`에는 3.14159265000000020862...가 저장되어 8자리까지 정확하게 출력된다. 소수점 이하 6자리까지는 유효숫자 7자리 안에 들므로 두 경우의 출력이 같다. 다음은 같은 출력문으로 `float`형 변수를 출력한 프로그램이다.

```c
#include <stdio.h>

int main(void)
{
    float pi = 3.14159265f;              // f suffix: float literal

    printf("pi = %.2f\n", pi);           // a float argument is promoted to double
    printf("pi = %.4f\n", pi);
    printf("pi = %f\n", pi);
    printf("pi = %.8f\n", pi);
    printf("pi = %e\n", pi);

    return 0;
}
```

```text
pi = 3.14
pi = 3.1416
pi = 3.141593
pi = 3.14159274
pi = 3.141593e+00
```

- **`float` 리터럴:** `3.14159265f`의 접미사 `f`는 이 리터럴이 `float`형임을 나타낸다. 접미사 없이 `float pi = 3.14159265;`로 쓰면 `double` 리터럴이 `float`로 변환되어 같은 값이 저장되며, `-Wall`은 이 변환에 경고를 내지 않는다([3장 4.1절](../Ch03_Data-Types-and-Variables/Concepts_Lecture.ko.md#41-리터럴-상수)).
- **출력 형식 지정자:** `float` 인자는 `printf`에 넘겨질 때 `double`로 변환되므로 두 프로그램의 형식 지정자는 같다. 이 변환은 이미 잃은 정밀도를 되살리지 않는다.

## 연습 문제 19: 8진수, 10진수, 16진수의 입력과 출력

**교재 문항:** 2장 프로그래밍 과제 9번

**문제:** 정수를 8진수(`012`), 10진수, 16진수(`0x12`) 중 하나로 입력받아 8진수, 10진수, 16진수로 출력하라. 문제 전문과 실행 예시는 [연습 문제 19](Exercises.ko.md#연습-문제-19-8진수-10진수-16진수의-입력과-출력)에 있다.

### 풀이

**접근 방법:** 입력은 접두사로 진법을 판단하는 `%i`로 받고, 출력은 `%#o`, `%d`, `%#x`로 한다([2장 2.3절](Concepts_Lecture.ko.md#23-scanf), [3장 5.1절](../Ch03_Data-Types-and-Variables/Concepts_Lecture.ko.md#51-주요-지정자)).

- **`%i` 입력:** `%d`는 입력을 항상 10진수로 해석하지만, `%i`는 C의 정수 상수처럼 접두사를 보고 진법을 정한다. `0x`나 `0X`로 시작하면 16진수, `0`으로 시작하면 8진수, 그 밖에는 10진수로 읽는다. `0x12`는 16 × 1 + 2 = 18로 저장된다.
- **`%#o`와 `%#x` 출력:** `%o`는 8진수, `%x`는 16진수로 출력하며, `#` 플래그를 붙이면 입력할 때와 같은 접두사 `0`과 `0x`가 붙는다. 18 = 8 × 2 + 2이므로 8진수로는 `022`이다.
- **정렬:** 실행 예시처럼 `8진수` 앞에 빈칸을 하나 두어 `10진수`, `16진수`와 콜론의 위치를 맞춘다.

**코드:**

```c
#define _CRT_SECURE_NO_WARNINGS  // allows scanf in Visual Studio
#include <stdio.h>

int main(void)
{
    int num;

    printf("8진수로 입력하려면 012, 16진수로 입력하려면 0x12처럼 입력하세요.\n");
    printf("정수? ");
    scanf("%i", &num);                   // %i accepts decimal, 012 (octal), 0x12 (hex)

    printf(" 8진수: %#o\n", num);        // # adds the prefix 0
    printf("10진수: %d\n", num);
    printf("16진수: %#x\n", num);        // # adds the prefix 0x

    return 0;
}
```

**실행 결과:** `0x12`를 입력한 결과는 다음과 같다. 8진수 `012`는 8 × 1 + 2 = 10이고, 10진수 `18`은 `0x12`와 같은 값이다.

```text
8진수로 입력하려면 012, 16진수로 입력하려면 0x12처럼 입력하세요.
정수? 0x12
 8진수: 022
10진수: 18
16진수: 0x12
```

```text
8진수로 입력하려면 012, 16진수로 입력하려면 0x12처럼 입력하세요.
정수? 012
 8진수: 012
10진수: 10
16진수: 0xa
```

```text
8진수로 입력하려면 012, 16진수로 입력하려면 0x12처럼 입력하세요.
정수? 18
 8진수: 022
10진수: 18
16진수: 0x12
```

> **주의:** **0과 8진수가 아닌 숫자.** `#` 플래그는 값이 0이면 접두사를 붙이지 않으므로 0을 입력하면 세 줄 모두 `0`이 출력된다. 또 `%i`는 0으로 시작하는 입력을 8진수로 읽으므로, `09`를 입력하면 8진수 숫자가 아닌 9 앞에서 읽기를 멈추어 값이 0이 된다. 10진수로 입력할 때는 앞에 0을 붙이지 않아야 한다.

```text
8진수로 입력하려면 012, 16진수로 입력하려면 0x12처럼 입력하세요.
정수? 09
 8진수: 0
10진수: 0
16진수: 0
```

10진수로 입력받은 값을 `%d`, `%#o`, `%#x`로 출력하는 비슷한 문제는 [HW02 문제 1](../../Coursework/HW02_Operators/Assignment-Explanation.ko.md#2-문제-1-값의-n진수-출력)에 있다. 그 문제는 입력을 `%d`로 받으므로 `0x12` 같은 입력은 0으로 읽힌다.
