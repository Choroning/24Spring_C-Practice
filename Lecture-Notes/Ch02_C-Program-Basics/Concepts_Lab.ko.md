## 1. 문자열 출력

### 1.1 printf로 문자열 출력하기

`printf` 함수는 큰따옴표(`" "`) 사이에 있는 내용을 콘솔 화면에 그대로 출력한다. `\n`은 줄바꿈을 나타내는 이스케이프 시퀀스이므로 화면에 글자로 나타나지 않고 다음 출력이 새 줄에서 시작되게 한다([2장 2.2절](Concepts_Lecture.ko.md#22-printf)).

```c
#include <stdio.h>

int main(void)
{
    printf("2022년 3월 1학기 C언어 강의\n");
    printf("3 + 3 = 6\n");          // the characters 3, +, 3, =, 6 are printed as they are
    printf("2 + 6 = 5 \n");         // no calculation happens inside a string

    return 0;
}
```

```text
2022년 3월 1학기 C언어 강의
3 + 3 = 6
2 + 6 = 5 
```

### 1.2 숫자 형태의 문자와 연산

위 프로그램의 둘째 줄은 `3 + 3 = 6`을 출력하지만, 이것은 컴퓨터가 덧셈을 한 결과가 아니다. 큰따옴표 안의 `3`, `+`, `=`, `6`은 모두 문자이며, `printf`는 그 문자들을 차례로 화면에 내보낼 뿐이다. 그래서 셋째 줄처럼 수학적으로 틀린 `2 + 6 = 5`도 아무 오류 없이 출력된다. 이처럼 큰따옴표 안에 있는 숫자는 연산할 수 있는 수가 아니라 **숫자 형태의 문자**이다.

컴퓨터가 실제로 덧셈을 하게 하려면 수를 큰따옴표 밖에 써서 수식으로 만들고, 계산 결과가 출력될 자리를 형식 지정자 `%d`로 알려 준다(3.2절).

```c
#include <stdio.h>

int main(void)
{
    printf("3 + 3 = 6\n");             // characters that look like numbers
    printf("3 + 3 = %d\n", 3 + 3);     // the integer 3 + 3 is computed, then printed

    return 0;
}
```

```text
3 + 3 = 6
3 + 3 = 6
```

두 줄의 출력은 같지만, 둘째 줄의 6은 `3 + 3`을 계산한 정수 값이다. 둘째 줄의 수식을 `3 + 4`로 바꾸면 출력도 7로 바뀌는 반면, 첫째 줄은 문자열을 고치지 않는 한 항상 6을 출력한다.

## 2. 변수

### 2.1 데이터를 보관하는 메모리 영역

수를 계산하려면 계산에 쓸 데이터를 보관해 두었다가 꺼내 쓸 공간이 필요하다. 컴퓨터에서 데이터를 보관하는 곳은 **메모리(memory)** 이며, 프로그래밍 언어는 메모리의 일부 영역에 데이터를 보관하고 사용한다.

> **용어 정의:** **변수(variable)** 는 프로그램이 데이터를 보관하는 메모리 영역이다. **변수 선언(variable declaration)** 은 컴퓨터에게 사용할 데이터를 위한 메모리 영역을 확보하도록 시키는 것이다.

C, C++, Java 같은 언어에서는 데이터를 사용하기 전에 그 데이터를 보관할 메모리 공간을 미리 확보해야 한다. 즉, 변수는 사용하기 전에 반드시 선언해야 한다([3장 3.1절](../Ch03_Data-Types-and-Variables/Concepts_Lecture.ko.md#31-선언과-초기화)).

### 2.2 데이터 타입과 메모리 크기

데이터에는 정수(`3`), 실수(`3.2`), 문자 하나(`'A'`, `'b'`), 문자열(`"Hello"`) 같은 종류가 있으며, 이를 **데이터 타입(data type)** 이라고 한다. C에서는 프로그래머가 어떤 종류의 데이터를 사용할지 `int`, `double` 같은 키워드로 명확하게 밝혀야 하고, 컴퓨터는 그 타입에 맞는 크기의 메모리를 확보한다.

| 데이터의 종류 | 키워드 | 메모리 크기 |
|:-----|:-----|:-----|
| 정수 | `int` | 4바이트 (32비트) |
| 실수 | `float` | 4바이트 (32비트) |
| 실수 | `double` | 8바이트 (64비트) |
| 문자 하나 | `char` | 1바이트 (8비트) |

*표 1. 데이터의 종류와 키워드, 메모리 크기*

**비트(bit)** 는 0 또는 1 하나를 보관하는 메모리의 한 칸이고, **바이트(byte)** 는 비트 8개를 묶은 단위이다. 따라서 4바이트의 `int` 변수는 4 × 8 = 32개의 비트로 정수 하나를 표현한다. 문자열은 문자 여러 개를 이어 붙인 것으로, 9장에서 따로 다룬다.

> **주의:** 표의 크기는 Visual Studio와 오늘날의 대부분의 PC 컴파일러에서의 값이다. C 표준은 `char`가 1바이트라는 것과 각 타입이 표현해야 하는 최소 범위만 정하므로, `int`의 크기는 플랫폼에 따라 다를 수 있다([3장 1.1절](../Ch03_Data-Types-and-Variables/Concepts_Lecture.ko.md#11-정수형)).

### 2.3 변수 선언과 변수 이름

`2 + 3 = 5`를 계산하는 프로그램에는 2, 3, 덧셈 결과 5라는 세 개의 정보가 있으므로 정수를 보관할 메모리 공간이 세 개 필요하다. 그렇다고 타입만 써서 `int;`를 세 번 선언하면, 메모리를 확보하더라도 프로그래머가 코드에서 그 메모리에 접근할 방법이 없다. 실제로 C에서 이름 없이 `int;`만 쓰는 선언은 아무 변수도 만들지 않으며, 컴파일러는 경고를 낸다.

변수를 선언할 때는 메모리 공간에 이름을 붙인다. 프로그램을 작성하는 시점에는 아직 메모리가 만들어지지 않았으므로, 프로그래머는 변수 이름으로 메모리 공간을 가리킨다. 프로그램이 실행되면 각 변수에 메모리가 할당되고, 컴퓨터는 변수 이름이 아니라 자동으로 부여된 **메모리 주소(memory address)** 로 그 메모리에 접근한다.

```c
int val_1;   // declares a variable and names it
int val_2;
int sum;
```

```text
 변수 이름        메모리 주소의 예      저장된 값
┌──────────┐    ┌──────────┐       ┌──────────┐
│  val_1   │ ─▶ │ 0xdefdd0 │ ─────▶│ garbage  │
├──────────┤    ├──────────┤       ├──────────┤
│  val_2   │ ─▶ │ 0xdefdc4 │ ─────▶│ garbage  │
├──────────┤    ├──────────┤       ├──────────┤
│  sum     │ ─▶ │ 0xdefdb8 │ ─────▶│ garbage  │
└──────────┘    └──────────┘       └──────────┘
```

*그림 1. 선언만 한 세 변수의 이름, 메모리 주소, 저장된 값*

그림의 주소는 실행할 때마다 달라질 수 있는 예이다. 선언만 하고 값을 주지 않은 지역 변수에는 그 메모리에 이전부터 남아 있던 알 수 없는 값, 즉 **쓰레기 값(garbage value)** 이 들어 있다.

### 2.4 초기화, 대입, 연산

변수에 값을 넣는 방법은 두 가지이다. 변수를 선언하면서 동시에 값을 넣는 것을 **초기화(initialization)** 라고 하고, 이미 선언된 변수에 나중에 값을 넣는 것을 **대입(assignment)** 이라고 한다.

```c
int val_1 = 2;   // initialization: declaration and assignment at once
```

C의 `=`는 수학의 등호와 뜻이 다르다. 수학에서 `=`는 왼쪽과 오른쪽이 같다는 뜻이지만, C에서 `=`는 오른쪽의 값을 왼쪽의 메모리 영역에 저장하라는 **대입 연산자(assignment operator)** 이다. `=`의 왼쪽(left-hand side)에 오는 것을 **L-value**, 오른쪽(right-hand side)에 오는 것을 **R-value**라고 하며, 항상 R-value의 값이 L-value가 가리키는 메모리 영역에 저장된다. 그래서 L-value에는 메모리 영역을 나타내는 변수가 와야 하고, `2 = val_1`처럼 상수를 왼쪽에 쓸 수 없다.

```c
#include <stdio.h>

int main(void)
{
    int val_1 = 2;              // declaration with initialization
    int val_2 = 3;
    int sum;                    // declaration only: the value is indeterminate

    sum = val_1 + val_2;        // read 2 and 3, add them, assign 5 to sum
    printf("val_1 + val_2 = sum \n");                    // names inside a string are just characters
    printf("%d + %d = %d \n", val_1, val_2, sum);        // %d marks where each value is printed

    return 0;
}
```

`sum = val_1 + val_2;`는 다음 순서로 실행된다.

1. 메모리에서 `val_1`의 값 2를 읽는다.
2. 메모리에서 `val_2`의 값 3을 읽는다.
3. 2 + 3을 계산한다.
4. 결과 5를 `sum`의 메모리 영역에 저장한다. 이때 `sum`에 있던 쓰레기 값은 5로 바뀐다.

## 3. 연산 결과의 출력

### 3.1 문자열 안의 변수 이름

2.4절 프로그램의 첫 번째 `printf`는 `2 + 3 = 5`가 아니라 다음을 출력한다.

```text
val_1 + val_2 = sum 
2 + 3 = 5 
```

`printf`는 큰따옴표 안의 문자열을 한 글자씩 출력할 뿐, 그 안의 `val_1`이나 `sum`을 변수 이름으로 인식하지 않는다. 변수의 값을 출력하려면 줄바꿈 문자 `\n`처럼 특별한 기호로 값이 출력될 위치를 문자열 안에 표시해야 한다.

### 3.2 형식 지정자

**형식 지정자(format specifier)** 는 변수의 값이 출력될 위치와 출력 형식을 지정하는 기호이며, 서식 지정자 또는 형식 문자라고도 한다. `printf("%d + %d = %d \n", val_1, val_2, sum);`은 다음과 같이 해석된다([2장 2.2절](Concepts_Lecture.ko.md#22-printf)).

- **형식 문자열:** 10진 정수가 출력될 세 자리에 `%d`를 하나씩 쓴다. `d`는 10진수(decimal)의 머리글자이다.
- **인자:** 큰따옴표가 끝난 뒤에 출력할 값을 형식 지정자의 순서대로 쓰고 쉼표로 구분한다. 첫 번째 `%d`에는 `val_1`의 값이, 두 번째에는 `val_2`의 값이, 세 번째에는 `sum`의 값이 들어간다.

| 데이터의 종류 | 변수 선언의 키워드 | 형식 지정자 |
|:-----|:-----|:-----|
| 정수 | `int` | `%d` (10진수), `%x` (16진수) |
| 실수 | `float`, `double` | `%f` (소수점 표기), `%e` (지수 표기) |
| 문자 | `char` | `%c` |

*표 2. 데이터의 종류에 따른 형식 지정자*

> **주의:** 형식 지정자와 인자의 타입이 맞지 않으면, 예를 들어 `double` 값을 `%d`로 출력하면 C 표준에서 정의되지 않은 동작이 되어 엉뚱한 값이 출력된다. 형식 지정자의 개수와 인자의 개수도 같아야 한다.

## 4. 실습 문제

다음 문제는 형식 지정자로 변수의 값을 출력하는 연습이다. 각 프로그램은 `gcc -std=c99 -Wall`로 경고 없이 컴파일되며, 출력은 실제로 실행한 결과이다.

### 4.1 정수 변수의 합

**문제:** 정수형 변수 `a`, `b`를 각각 20, -5로 초기화하고, 두 변수의 값과 합을 `20 + -5 = 15` 형식으로 출력하라.

**풀이:** 세 값이 출력될 자리에 `%d`를 쓰고, 합은 따로 변수에 저장하지 않고 수식 `a + b`를 인자로 넘긴다. 인자로 쓴 수식은 `printf`가 호출되기 전에 계산된다. 음수는 `%d`가 부호를 붙여 출력한다.

```c
#include <stdio.h>

int main(void)
{
    int a = 20, b = -5;

    printf("%d + %d = %d\n", a, b, a + b);

    return 0;
}
```

```text
20 + -5 = 15
```

### 4.2 실수 변수의 합과 차

**문제:** 소수점 이하 2자리까지의 값을 갖는 변수 `ave`, `sum`을 각각 10.25, 4.32로 초기화하고, 두 변수의 합과 차를 출력하라.

**풀이:** 소수가 있는 값이므로 실수형 변수를 쓰고 형식 지정자 `%f`로 출력한다. 여기서는 정밀도가 높은 `double`을 쓴다([3장 1.2절](../Ch03_Data-Types-and-Variables/Concepts_Lecture.ko.md#12-실수형)).

```c
#include <stdio.h>

int main(void)
{
    double ave = 10.25, sum = 4.32;

    printf("%f + %f = %f\n", ave, sum, ave + sum);
    printf("%f - %f = %f\n", ave, sum, ave - sum);

    return 0;
}
```

```text
10.250000 + 4.320000 = 14.570000
10.250000 - 4.320000 = 5.930000
```

`%f`는 따로 지정하지 않으면 소수점 아래 6자리까지 출력하므로 `10.25`가 `10.250000`으로 나타난다.

### 4.3 소수점 이하 자릿수 지정

**문제:** 4.2절의 출력을 `10.25 + 4.32 = 14.57`처럼 소수점 이하 2자리까지만 나타나도록 바꾸라.

**풀이:** `%`와 `f` 사이에 `.2`를 넣어 `%.2f`로 쓰면 소수점 아래 2자리까지 출력하고, 그 다음 자리에서 반올림한다([3장 5.2절](../Ch03_Data-Types-and-Variables/Concepts_Lecture.ko.md#52-출력-폭과-정렬)). 4.2절 프로그램의 두 `printf`를 다음과 같이 바꾼다.

```c
printf("%.2f + %.2f = %.2f\n", ave, sum, ave + sum);
printf("%.2f - %.2f = %.2f\n", ave, sum, ave - sum);
```

```text
10.25 + 4.32 = 14.57
10.25 - 4.32 = 5.93
```

> **참고:** 10.25 - 4.32는 2진수로 정확히 표현되지 않는 실수의 연산이므로 내부 값은 5.93에 아주 가까운 근삿값이다. `%f`나 `%.2f`는 출력할 자리에서 반올림하므로 이 차이가 보이지 않지만, `%.17f`처럼 자릿수를 늘리면 드러난다([3장 1.2절](../Ch03_Data-Types-and-Variables/Concepts_Lecture.ko.md#12-실수형)).

### 4.4 문자의 ASCII 값

**문제:** 변수 `ch`를 임의의 영문자(여기서는 `'A'`)로 초기화하고, 그 영문자의 ASCII 값을 출력하라. `printf("'A'의 ASCII값은 65입니다! \n");`처럼 값을 문자열에 직접 쓰면 안 된다.

**풀이:** `char` 변수는 문자를 그 문자의 코드인 정수로 저장한다. 따라서 같은 변수를 `%c`로 출력하면 문자가, `%d`로 출력하면 코드 값이 나온다([3장 1.3절](../Ch03_Data-Types-and-Variables/Concepts_Lecture.ko.md#13-문자형)).

```c
#include <stdio.h>

int main(void)
{
    char ch = 'A';

    printf("%c의 ASCII값은 %d입니다!\n", ch, ch);   // the same value printed as a character and as an integer

    return 0;
}
```

```text
A의 ASCII값은 65입니다!
```

**ASCII(American Standard Code for Information Interchange)** 는 영문자, 숫자, 기호에 0~127의 번호를 붙인 미국 정보 교환 표준 부호이다. 다음은 그 일부이다.

| 10진수 | 16진수 | 문자 | 10진수 | 16진수 | 문자 | 10진수 | 16진수 | 문자 |
|-----:|-----:|:---:|-----:|-----:|:---:|-----:|-----:|:---:|
| 32 | 0x20 | (공백) | 64 | 0x40 | `@` | 96 | 0x60 | `` ` `` |
| 33 | 0x21 | `!` | 65 | 0x41 | `A` | 97 | 0x61 | `a` |
| 34 | 0x22 | `"` | 66 | 0x42 | `B` | 98 | 0x62 | `b` |
| 35 | 0x23 | `#` | 67 | 0x43 | `C` | 99 | 0x63 | `c` |
| 36 | 0x24 | `$` | 68 | 0x44 | `D` | 100 | 0x64 | `d` |
| 37 | 0x25 | `%` | 69 | 0x45 | `E` | 101 | 0x65 | `e` |
| 38 | 0x26 | `&` | 70 | 0x46 | `F` | 102 | 0x66 | `f` |

*표 3. ASCII 코드 값의 일부*

대문자와 소문자의 코드는 32(0x20)만큼 차이가 나므로, `'a' - 'A'`는 32이다.

## 점검 문제

1. **문자열과 수식:** `printf("5 * 4 = 20\n");`과 `printf("5 * 4 = %d\n", 5 * 4);`는 같은 결과를 출력한다. 두 문장의 차이는 무엇인가?

   <details>
   <summary>정답</summary>

   첫 문장은 큰따옴표 안의 문자 `5 * 4 = 20`을 그대로 출력할 뿐 곱셈을 하지 않는다. 둘째 문장은 수식 `5 * 4`를 계산한 정수 20을 `%d` 자리에 출력한다. 숫자를 바꾸어 `5 * 5`로 쓰면 첫 문장은 고친 문자열을 그대로 출력하므로 결과가 틀릴 수 있지만, 둘째 문장은 계산 결과인 25를 출력한다.

   </details>

2. **L-value:** `val_1 = 2;`는 올바르지만 `2 = val_1;`은 컴파일 오류이다. 그 이유를 L-value와 R-value로 설명하라.

   <details>
   <summary>정답</summary>

   대입 연산자 `=`는 R-value의 값을 L-value가 가리키는 메모리 영역에 저장한다. `val_1`은 메모리 영역을 가진 변수이므로 L-value가 될 수 있지만, 상수 2에는 값을 저장할 메모리 영역이 없으므로 L-value가 될 수 없다.

   </details>

3. **쓰레기 값:** `int sum;`만 선언하고 `printf("%d\n", sum);`을 실행하면 어떤 값이 출력되는가?

   <details>
   <summary>정답</summary>

   초기화하지 않은 지역 변수에는 그 메모리에 남아 있던 알 수 없는 쓰레기 값이 들어 있으므로, 실행할 때마다 다른 값이 출력될 수 있다. C 표준에서는 이러한 값을 사용하는 것 자체를 피해야 하므로, 변수는 사용하기 전에 초기화하거나 값을 대입한다.

   </details>

4. **형식 지정자:** `double` 변수 `x`의 값 3.14159를 `3.14`로 출력하는 `printf` 문장을 쓰라. 또 `char` 변수 `c`에 `'a'`가 들어 있을 때 `printf("%d", c);`의 출력은 무엇인가?

   <details>
   <summary>정답</summary>

   `printf("%.2f\n", x);`이다. `%.2f`는 소수점 아래 둘째 자리까지 반올림하여 출력한다. `'a'`의 ASCII 코드는 97이므로 `printf("%d", c);`는 97을 출력한다.

   </details>
