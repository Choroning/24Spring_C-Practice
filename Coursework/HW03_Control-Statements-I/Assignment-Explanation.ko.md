## 1. 과제 구성과 실행 방법

4장의 연산자를 다루는 네 문제로 이루어진 과제이다. 문제 1과 3은 주어진 프로그램의 실행 결과를 쓰고 그 결과가 나오는 이유를 설명하는 서술 문항, 문제 2는 말로 주어진 조건을 관계 연산과 논리 연산의 수식으로 표현하는 서술 문항, 문제 4는 `if`문 없이 조건 연산자만으로 세 정수 중 가장 큰 값을 구하는 코드 작성 문항이다. 문제 1은 교재 4장 연습 문제 7번을 일부 바꾼 것이고, 문제 2는 5장 연습 문제 1번을 `if`문 없이 답하도록 바꾼 것이다. 조건 연산자는 조건에 따라 두 값 중 하나를 고르는 수식이므로, 문제 4는 선택 구조를 문장이 아니라 수식으로 표현하는 연습이 된다.

## 2. 문제 1: 연산자의 결과값

### 2.1 문제

**교재 문항:** 4장 연습 문제 7번(일부 변경)

다음 프로그램의 결과를 작성하고, 해당 결과가 나오는 이유를 설명하라.

```c
#include <stdio.h>
int main()
{
	int no = 10, count = 20;
	char ch = 'a';
	printf(" %d", no > count);
	printf(" %d", no < count * 4);
	printf(" %d", (no != 10) || (count >= 20));
	printf(" %d", (no <= 10) && (count > 20));
	printf("\n------\n");
	printf(" %d \n", !(no > count));
	printf(" %d \n", 3);
	printf(" %d \n", ch);
	printf(" %d \n", 'b');
	printf(" %d \n", sizeof(3.2));
	printf(" %d \n", sizeof(3.2f));
	printf(" %d \n", sizeof(float));
	printf(" %d \n", sizeof(double));
}
```

### 2.2 풀이

**접근 방법:** 관계 연산자와 논리 연산자는 참이면 1, 거짓이면 0을 `int`형 값으로 낸다([4장 4.2절](../../Lecture-Notes/Ch04_Operators/Concepts_Lecture.ko.md#42-결과-타입), [4장 5.4절](../../Lecture-Notes/Ch04_Operators/Concepts_Lecture.ko.md#54-c에서의-참과-거짓)). `char`형 값과 문자 상수를 `%d`로 출력하면 문자 코드가 나오고, `sizeof`는 피연산자의 크기를 바이트 수로 낸다([3장 7절](../../Lecture-Notes/Ch03_Data-Types-and-Variables/Concepts_Lecture.ko.md#7-sizeof-연산자)). 각 `printf`가 출력하는 값과 그 이유는 다음과 같다.

| 출력하는 수식 | 값 | 이유 |
|:-----|:-----|:-----|
| `no > count` | 0 | 10 > 20은 거짓이다. |
| `no < count * 4` | 1 | `*`가 `<`보다 우선순위가 높아 10 < 80으로 계산되고, 이는 참이다. |
| `(no != 10) \|\| (count >= 20)` | 1 | 왼쪽의 10 != 10은 거짓이지만 오른쪽의 20 >= 20이 참이므로 `\|\|`의 결과는 1이다. |
| `(no <= 10) && (count > 20)` | 0 | 왼쪽의 10 <= 10은 참이지만 오른쪽의 20 > 20이 거짓이므로 `&&`의 결과는 0이다. |
| `!(no > count)` | 1 | `no > count`가 0이므로 `!0`은 1이다. |
| `3` | 3 | 정수 상수 3이 그대로 출력된다. |
| `ch` | 97 | `ch`에는 `'a'`의 ASCII 코드 97이 저장되어 있고, `printf`에 넘길 때 `int`로 승격된다. |
| `'b'` | 98 | C에서 문자 상수는 `int`형이며, 그 값은 `'b'`의 ASCII 코드 98이다. |
| `sizeof(3.2)` | 8 | 접미사가 없는 실수 상수는 `double`형이다. |
| `sizeof(3.2f)` | 4 | 접미사 `f`를 붙인 실수 상수는 `float`형이다. |
| `sizeof(float)` | 4 | `float`형의 크기이다. |
| `sizeof(double)` | 8 | `double`형의 크기이다. |

*표 1. 문제 1의 각 수식이 출력하는 값*

`float`와 `double`의 크기는 C 표준이 정하지 않지만, IEEE 754 형식을 쓰는 대부분의 환경에서 각각 4바이트와 8바이트이다. `||`와 `&&`는 왼쪽 피연산자만으로 결과가 정해지면 오른쪽을 평가하지 않는데([4장 5.3절](../../Lecture-Notes/Ch04_Operators/Concepts_Lecture.ko.md#53-단락-평가)), 이 프로그램의 두 논리 수식은 왼쪽만으로 결과가 정해지지 않으므로 오른쪽까지 평가된다.

출력 형식도 결과의 일부이다. 처음 네 `printf`는 형식 문자열 `" %d"`에 줄바꿈이 없으므로 네 값이 공백으로 구분되어 한 줄에 이어진다. 다섯 번째 `printf("\n------\n")`가 그 줄을 끝내고 `------`를 출력한 뒤 다시 줄을 바꾼다. 나머지 여덟 줄은 형식 문자열이 `" %d \n"`이므로 값의 앞과 뒤에 공백이 하나씩 붙는다.

### 2.3 실행 결과

문제의 프로그램을 그대로 컴파일하여 실행한 결과는 다음과 같다. 표 1의 값이 위의 출력 형식대로 나온다.

```text
 0 1 1 0
------
 1 
 3 
 97 
 98 
 8 
 4 
 4 
 8 
```

> **주의:** `sizeof`의 결과는 부호 없는 정수형 `size_t`이므로, 이 프로그램을 `gcc -std=c99 -Wall`로 컴파일하면 `sizeof`를 `%d`로 출력하는 네 줄에 형식 불일치 경고(`-Wformat`)가 나온다. 이 환경에서도 위와 같은 값이 출력되지만, `size_t`가 `int`보다 큰 64비트 환경에서 `%d`로 출력하는 것은 원칙적으로 정의되지 않은 동작이다. C99 이후에는 `printf(" %zu \n", sizeof(3.2));`처럼 `%zu`를 쓰거나, `(int)sizeof(3.2)`처럼 `int`로 변환하여 `%d`로 출력한다.

## 3. 문제 2: 조건의 수식 표현

### 3.1 문제

**교재 문항:** 5장 연습 문제 1번(변경)

다음 설명을 컴퓨터 수식(관계 연산 및 논리 연산 등 활용)으로 표현하라. `if`문을 배우기 전이므로 수식으로만 표현한다.

- (1) 정수 `number`가 1보다 크고 10 미만이다.
- (2) 정수 `number`는 1 ~ 10에 속한다.
- (3) 문자 상수 `ch`는 `'q'`도 아니고 `'z'`도 아니다.
- (4) `no`는 1과 10 사이의 수이지만 5는 아니다.
- (5) `no`는 1과 10 사이의 수가 아니다.
- (6) `ch`는 공백 문자(`' '`)이거나 개행 문자(`'\n'`)이다.

### 3.2 풀이

**접근 방법:** 수학의 범위 표기 1 < x < 10은 두 비교가 모두 성립한다는 뜻이므로, C에서는 두 관계식을 `&&`로 잇는다. 설명에서 두 조건이 함께 성립해야 하면 `&&`로, 둘 중 하나만 성립해도 되면 `||`로 잇고, 부정은 반대 방향의 관계 연산자나 `!`로 나타낸다. 관계 연산자는 논리 연산자보다, `&&`는 `||`보다 우선순위가 높으므로([4장 10.1절](../../Lecture-Notes/Ch04_Operators/Concepts_Lecture.ko.md#101-우선순위-표)) 아래 수식에는 괄호가 필요 없다.

| 항목 | 수식 | 같은 뜻의 다른 수식 |
|:-----|:-----|:-----|
| (1) | `number > 1 && number < 10` | `1 < number && number < 10` |
| (2) | `number >= 1 && number <= 10` | `!(number < 1 \|\| number > 10)` |
| (3) | `ch != 'q' && ch != 'z'` | `!(ch == 'q' \|\| ch == 'z')` |
| (4) | `no >= 1 && no <= 10 && no != 5` | `(no >= 1 && no <= 10) && !(no == 5)` |
| (5) | `no < 1 \|\| no > 10` | `!(no >= 1 && no <= 10)` |
| (6) | `ch == ' ' \|\| ch == '\n'` | `!(ch != ' ' && ch != '\n')` |

*표 2. 각 설명에 대응하는 수식*

- **범위의 양 끝:** (1)은 1과 10을 포함하지 않으므로 `>`와 `<`를, (2)는 1과 10을 포함하므로 `>=`와 `<=`를 쓴다. (4)와 (5)의 "1과 10 사이"는 (2)와 같이 1과 10을 포함하는 범위로 본다. 양 끝을 빼는 뜻이면 (1)처럼 `>`와 `<`로 바꾼다.
- **부정과 드모르간 법칙:** (5)는 (2)의 부정이다. 드모르간 법칙에 따라 `!(A && B)`는 `!A || !B`와 같으므로, `!(no >= 1 && no <= 10)`은 `!(no >= 1) || !(no <= 10)`, 곧 `no < 1 || no > 10`이 된다. (3)의 두 수식도 `!(A || B)`가 `!A && !B`와 같다는 같은 법칙으로 서로 바뀐다.
- **경계값 점검:** (1)의 수식은 `number`가 1이면 0, 2이면 1, 9이면 1, 10이면 0이고, (2)의 수식은 1과 10에서도 1이다. (4)는 (2)와 달리 5에서 0이 된다. 표의 두 수식은 -20부터 30까지의 정수와 ASCII 코드 0부터 127까지의 문자 모두에서 같은 값을 낸다.

> **주의:** **흔한 잘못.** (1)을 수학처럼 `1 < number < 10`으로 쓰면 컴파일은 되지만 `(1 < number) < 10`으로 계산된다. 왼쪽 비교의 결과는 0 또는 1이고 둘 다 10보다 작으므로, 이 수식은 `number`의 값과 관계없이 항상 1이다. gcc와 clang은 `-Wall`에서 이 수식에 경고를 낸다. 또 (3)을 `ch != 'q' || ch != 'z'`로 쓰면, 한 문자가 `'q'`와 `'z'`에 동시에 같을 수는 없으므로 두 비교 중 하나는 반드시 참이 되어 항상 1이 된다.

## 4. 문제 3: 증감 연산과 대입

### 4.1 문제

다음 프로그램의 결과를 작성하고, 해당 결과가 나오는 이유를 설명하라.

```c
#include <stdio.h>

int main()
{
	int a = 3, b = 0;
	printf("%d , %d \n", a, b);

	b = ++a * 2;
	printf("%d , %d \n", a, b);

	a = b-- * 2;
	printf("%d , %d \n", a, b);

	a = a++ % 4;
	printf("%d , %d \n", a, b);

	a += a * b;
	printf("%d , %d \n", a, b);
}
```

### 4.2 풀이

**접근 방법:** 전위 증가 `++a`는 `a`를 먼저 1 늘린 뒤 늘어난 값을 수식에 쓰고, 후위 감소 `b--`는 `b`의 현재 값을 수식에 쓴 뒤 1 줄인다([4장 3.1절](../../Lecture-Notes/Ch04_Operators/Concepts_Lecture.ko.md#31-전위-vs-후위)). 증감 연산자는 `*`, `%`보다 우선순위가 높으므로 `++a * 2`는 `(++a) * 2`로 계산된다. 복합 대입 `a += a * b`는 `a = a + (a * b)`와 같다([4장 7.1절](../../Lecture-Notes/Ch04_Operators/Concepts_Lecture.ko.md#71-단순-대입과-복합-대입)). 각 문장을 실행한 뒤의 값은 다음과 같다.

| 문장 | 계산 | `a` | `b` |
|:-----|:-----|:-----|:-----|
| `int a = 3, b = 0;` | 초기화한다. | 3 | 0 |
| `b = ++a * 2;` | `a`가 4가 된 뒤 4 * 2 = 8을 `b`에 대입한다. | 4 | 8 |
| `a = b-- * 2;` | `b`의 현재 값 8로 8 * 2 = 16을 `a`에 대입하고, `b`는 7이 된다. | 16 | 7 |
| `a = a++ % 4;` | 16 % 4 = 0을 대입하는 것과 `a++`가 `a`를 17로 만드는 것의 순서가 정해져 있지 않다(4.3절). gcc와 clang에서는 0이 남는다. | 0 | 7 |
| `a += a * b;` | `a = 0 + 0 * 7`이므로 0이다. | 0 | 7 |

*표 3. 문제 3의 문장별 변수 값*

각 `printf`는 그 시점의 `a`, `b`를 형식 문자열 `"%d , %d \n"`대로 출력하므로, 줄마다 두 값 사이에 ` , `가 들어가고 줄 끝에 공백이 하나 남는다.

### 4.3 실행 결과와 정의되지 않은 동작

문제의 프로그램을 gcc와 clang으로 각각 컴파일하여 실행한 결과는 같으며, 다음과 같다.

```text
3 , 0 
4 , 8 
16 , 7 
0 , 7 
0 , 7 
```

넷째 줄의 0은 C 표준이 보장하는 결과가 아니다. `a = a++ % 4;`에서는 `a++`의 부수 효과(`a`에 17을 저장)와 대입(`a`에 0을 저장)이 같은 변수를 바꾸는데, C 표준은 이 두 수정의 순서를 정하지 않는다. 한 수식 안에서 같은 변수를 순서 없이 두 번 수정하는 것은 **정의되지 않은 동작(undefined behavior)** 이므로, 컴파일러는 어느 쪽을 먼저 반영해도 되고 다른 결과를 내도 된다. gcc는 `-Wall`에서 "operation on 'a' may be undefined" 경고(`-Wsequence-point`)를, clang은 "multiple unsequenced modifications to 'a'" 경고(`-Wunsequenced`)를 낸다. 대입이 나중에 반영되면 위처럼 0이 남지만, 증가가 나중에 반영되도록 번역하는 컴파일러에서는 다른 값이 남고 마지막 줄도 달라진다. 예를 들어 넷째 줄에서 `a`가 1이면 마지막 줄은 1 + 1 * 7 = 8이므로 `8 , 7`이 된다.

> **주의:** 의도한 계산이 나머지 연산뿐이면 `a = a % 4;`로 쓰고, 증가가 먼저라면 `a++;` 다음 줄에 `a = a % 4;`를 쓰는 식으로 한 문장에서 같은 변수를 한 번만 수정한다. 앞의 두 문장 `b = ++a * 2;`와 `a = b-- * 2;`는 각각 `a`와 `b`를 한 번씩만 수정하므로 결과가 정해져 있다.

## 5. 문제 4: 대소 비교

### 5.1 문제

공백으로 구분된 3개의 정수 정보를 사용자로부터 입력받은 후 가장 큰 값을 출력하라. 조건 연산자만을 사용해야 한다.

**실행 예시:**

```text
Input 3 values: 3 -4 9
Max: 9

Program ended with exit code: 0
```

```text
Input 3 values: 23 4 -5
Max: 23

Program ended with exit code: 0
```

```text
Input 3 values: -12 -3 -24
Max: -3

Program ended with exit code: 0
```

### 5.2 풀이

**접근 방법:** 조건 연산자 `조건 ? 값1 : 값2`는 조건이 참이면 값1을, 거짓이면 값2를 수식의 값으로 낸다([4장 8.1절](../../Lecture-Notes/Ch04_Operators/Concepts_Lecture.ko.md#81-삼항-연산자)). 두 값의 최댓값은 조건 연산자 하나로 구할 수 있으므로, 세 값의 최댓값은 두 단계로 나누어 구한다.

- **1단계:** `max1 = num1 > num2 ? num1 : num2;`로 앞의 두 수 중 큰 값을 구한다.
- **2단계:** `max2 = max1 > num3 ? max1 : num3;`로 1단계의 결과와 세 번째 수 중 큰 값을 구한다. 이 값이 세 수의 최댓값이다.
- **괄호가 없어도 되는 이유:** 관계 연산자 `>`는 조건 연산자보다, 조건 연산자는 대입 연산자보다 우선순위가 높다([4장 10.1절](../../Lecture-Notes/Ch04_Operators/Concepts_Lecture.ko.md#101-우선순위-표)). 따라서 `max1 = num1 > num2 ? num1 : num2`는 `max1 = ((num1 > num2) ? num1 : num2)`로 계산된다.

**코드:** [Solution/Q4.c](Solution/Q4.c)

```c
/**
 * @file    A10303-1_C05Q1.c
 * @brief   Q1. 대소 비교
 * @author  박철원 (Cheolwon Park)
 * @date    2024-03-28
 * 
 * @note    소스 코드에 사용된 scanf_s는 Visual Studio 이외의
 *	    IDE에서 실행이 불가할 수 있음에 주의하시기 바랍니다.
 */

#include <stdio.h>

int main()
{
	int num1, num2, num3;
	int max1, max2;

	printf("Input 3 values: ");
	scanf_s(" %d %d %d", &num1, &num2, &num3);

	max1 = num1 > num2 ? num1 : num2;
	max2 = max1 > num3 ? max1 : num3;

	printf("Max: %d", max2);
}
```

### 5.3 실행 결과와 경계 조건

**실행 결과:** 세 실행 예시와 같다. 출력 끝에 줄바꿈을 출력하지 않는다. 세 번째 실행에서는 -12 > -3이 거짓이므로 `max1`이 -3이 되고, -3 > -24가 참이므로 `max2`도 -3이 된다.

```text
Input 3 values: 3 -4 9
Max: 9
Input 3 values: 23 4 -5
Max: 23
Input 3 values: -12 -3 -24
Max: -3
```

> **참고:** **같은 값이 있을 때.** 두 수가 같으면 `num1 > num2`가 거짓이 되어 `num2`가 선택되지만, 두 값이 같으므로 결과는 달라지지 않는다. 세 수가 모두 같아도 그 값이 그대로 출력된다. 중간 변수 없이 하나의 수식으로 쓰려면 `num1 > num2 ? (num1 > num3 ? num1 : num3) : (num2 > num3 ? num2 : num3)`처럼 조건 연산자를 중첩한다.

```text
Input 3 values: 5 5 5
Max: 5
```

## 점검 문제

1. **관계 연산과 논리 연산의 값:** `int x = 7;`일 때 `printf("%d %d", x > 5 && x < 7, !(x % 2));`의 출력을 쓰라.

   <details>
   <summary>정답</summary>

   `0 0`이다. `x > 5`는 참이지만 `x < 7`이 거짓이므로 `&&`의 결과는 0이다. `x % 2`는 1이므로 `!1`은 0이다.

   </details>

2. **범위 조건의 부정:** 정수 `score`가 0 이상 100 이하가 아니라는 조건을 `!` 없이 수식으로 쓰라.

   <details>
   <summary>정답</summary>

   `score < 0 || score > 100`이다. `score >= 0 && score <= 100`의 부정에 드모르간 법칙을 적용하면 `&&`가 `||`로 바뀌고 각 비교가 반대가 된다.

   </details>

3. **후위 증가와 대입:** `int a = 5, b; b = a++ + 2;`를 실행한 뒤 `a`와 `b`의 값을 쓰고, 이 문장이 `a = a++ % 4;`와 달리 결과가 정해져 있는 이유를 쓰라.

   <details>
   <summary>정답</summary>

   `a`는 6, `b`는 7이다. `a++`는 현재 값 5를 수식에 쓰고 `a`를 6으로 늘리며, 5 + 2 = 7이 `b`에 대입된다. 이 문장은 `a`를 `a++`로 한 번, `b`를 대입으로 한 번만 수정하므로 반영 순서에 따라 결과가 달라지지 않는다.

   </details>

4. **조건 연산자의 평가:** `int x = 1, y = 0; int r = x ? 10 : y++;`를 실행한 뒤 `r`과 `y`의 값을 쓰라.

   <details>
   <summary>정답</summary>

   `r`은 10, `y`는 0이다. 조건 `x`가 참(0이 아님)이므로 두 번째 피연산자 10이 수식의 값이 되고, 세 번째 피연산자 `y++`는 평가되지 않는다. 조건 연산자는 두 값 중 선택된 쪽만 평가한다.

   </details>

5. **중간 과정 추적:** 입력이 `23 4 -5`일 때 `max1`과 `max2`의 값을 차례로 쓰라.

   <details>
   <summary>정답</summary>

   23 > 4가 참이므로 `max1`은 23이고, 23 > -5가 참이므로 `max2`는 23이다.

   </details>

6. **최솟값:** 같은 방법으로 세 값 중 가장 작은 값을 구하려면 코드의 어느 부분을 바꾸어야 하는가?

   <details>
   <summary>정답</summary>

   두 조건 연산자의 비교를 `>`에서 `<`로 바꾼다. `min1 = num1 < num2 ? num1 : num2;`, `min2 = min1 < num3 ? min1 : num3;`이 세 값의 최솟값이다.

   </details>

7. **하나의 수식:** 중간 변수 없이 조건 연산자만으로 `a`, `b`, `c`의 최댓값을 구하는 수식을 쓰고, `a = 5, b = 9, c = 7`일 때의 값을 구하라.

   <details>
   <summary>정답</summary>

   `a > b ? (a > c ? a : c) : (b > c ? b : c)`이다. 5 > 9가 거짓이므로 `(b > c ? b : c)`가 평가되고, 9 > 7이 참이므로 값은 9이다.

   </details>
