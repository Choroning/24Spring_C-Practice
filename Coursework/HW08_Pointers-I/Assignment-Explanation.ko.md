## 1. 맞바꾸기

### 1.1 문제

실행 예시를 참고하여 두 변수에 저장된 데이터를 맞바꾸는 프로그램을 작성하라. `main()`에는 `int a = 3, b = 5;`라는 변수가 있으며, 포인터를 사용해 두 값을 바꾸는 `swap()` 함수를 정의하여 활용한다.

**실행 예시:**

```text
초기상태: a = 3, b = 5
맞바꾸기: a = 5, b = 3

Program ended with exit code: 0
```

### 1.2 풀이

**접근 방법:** 값에 의한 전달로는 `swap()` 안에서 매개변수를 바꿔도 `main()`의 `a`, `b`가 바뀌지 않는다. 그래서 `swap()`의 매개변수를 `int*`로 선언하여 두 변수의 주소를 받고, 역참조로 원본을 교환한다([8장 3.2절](../../Lecture-Notes/Ch08_Pointers/Concepts_Lecture.ko.md#32-포인터를-통한-변수-수정)).

- **`swap(int* a, int* b)`:** `*a`의 값을 임시 변수 `tmp`에 저장하고, `*a = *b;`로 `b`가 가리키는 값을 `a`가 가리키는 곳에 복사한 뒤, `*b = tmp;`로 처음 값을 옮긴다. 임시 변수가 없으면 `*a = *b;`를 실행하는 순간 원래 `*a`의 값이 사라진다.
- **`main()`:** 교환 전의 값을 출력하고, `swap(&a, &b);`로 두 변수의 주소를 전달한 뒤 교환 후의 값을 출력한다.

**코드:** [Solution/Q1.c](Solution/Q1.c)

```c
/**
 * @file    A10303-1_C08Q1.c
 * @brief   Q1. 맞바꾸기
 * @author  박철원 (Cheolwon Park)
 * @date    2024-05-18
 */

#include <stdio.h>

void swap(int* a, int* b)
{
	int tmp = *a;
	*a = *b;
	*b = tmp;
}

int main()
{
	int a = 3, b = 5;
	printf("초기상태: a = %d, b = %d\n", a, b);
	swap(&a, &b);
	printf("맞바꾸기: a = %d, b = %d\n", a, b);
}
```

### 1.3 실행 결과

`gcc -std=c99 -Wall`로 경고 없이 컴파일되며, 실행 결과는 다음과 같다.

```text
초기상태: a = 3, b = 5
맞바꾸기: a = 5, b = 3
```

실행 예시와 같다. 실행 예시의 마지막 줄 `Program ended with exit code: 0`은 프로그램의 출력이 아니라 Xcode 콘솔이 덧붙이는 종료 메시지이며, 이 문서의 다른 실행 예시에서도 마찬가지이다. `main()`에 `return 0;`이 없지만, C99부터는 `main()`의 끝에 도달하면 0을 반환한 것으로 처리하므로 종료 코드는 0이다.

> **주의:** `swap()` 안에서 `int *tmp = a; a = b; b = tmp;`처럼 포인터 자체를 교환하면 `main()`의 변수는 바뀌지 않는다. 포인터 매개변수 `a`, `b`도 주소를 복사받은 지역 변수이므로, 원본을 바꾸려면 반드시 `*a`, `*b`처럼 역참조하여 가리키는 값을 바꿔야 한다.

## 2. 배열 연산

### 2.1 문제

아래와 같이 선언된 3개의 배열 `arrX`, `arrY`, `arrZ`가 있다.

```c
int arrX[4] = { -2, 4, 6, -32 };
int arrY[4] = { 4, 3, -5, 6 };
int arrZ[4] = { 0 };
```

아래에 주어진 함수의 선언을 바꾸지 않고 활용하여 `arrX`와 `arrY`의 원소끼리 더한 뒤, 연산 결과를 `arrZ` 배열에 저장하고 배열의 내용을 출력하라.

```c
void arrSum(int* pX, int* pY, int* pZ);
```

**실행 예시:**

```text
arrZ:  2   7   1  -26

Program ended with exit code: 0
```

### 2.2 풀이

**접근 방법:** 주어진 원형에는 배열의 크기를 받는 매개변수가 없다. 그래서 `arrSum()`이 원소 하나의 덧셈을 맡고, `main()`이 반복문으로 각 원소의 주소를 전달하는 방식을 택한다. 함수가 배열 전체를 처리하게 하려면 크기를 함수 안에 4로 고정해야 하는데, 그러면 다른 크기의 배열에 쓸 수 없다.

- **`arrSum()`:** 세 포인터가 가리키는 원소에 대해 `*pZ = *pX + *pY;`를 계산한다. `pZ`가 가리키는 `arrZ`의 원소가 결과로 바뀌므로 `pZ`는 출력 매개변수이다([8장 3.3절](../../Lecture-Notes/Ch08_Pointers/Concepts_Lecture.ko.md#33-여러-값-반환)).
- **`main()`:** `i = 0`부터 3까지 `arrSum(&arrX[i], &arrY[i], &arrZ[i]);`를 호출한다. `&arrX[i]`는 `arrX + i`와 같은 주소이다. 계산이 끝나면 `arrZ`의 원소를 `%3d`와 공백 두 칸으로 출력한다.

원소별 계산은 -2 + 4 = 2, 4 + 3 = 7, 6 + (-5) = 1, -32 + 6 = -26이다.

**코드:** [Solution/Q2.c](Solution/Q2.c)

```c
/**
 * @file    A10303-1_C08Q2.c
 * @brief   Q2. 배열 연산
 * @author  박철원 (Cheolwon Park)
 * @date    2024-05-18
 */

#include <stdio.h>

void arrSum(int* pX, int* pY, int* pZ)
{
	*pZ = *pX + *pY;
}

int main()
{
	int arrX[4] = { -2, 4, 6, -32 };
	int arrY[4] = { 4, 3, -5, 6 };
	int arrZ[4] = { 0 };

	for (int i = 0; i < 4; i++)
		arrSum(&arrX[i], &arrY[i], &arrZ[i]);

	printf("\narrZ: ");
	for (int i = 0; i < 4; i++)
		printf("%3d  ", arrZ[i]);
}
```

### 2.3 실행 결과

`gcc -std=c99 -Wall`로 경고 없이 컴파일되며, 실행 결과는 다음과 같다.

```text

arrZ:   2    7    1  -26  
```

네 합은 실행 예시와 같다. 출력 형식에는 차이가 있다. `printf("\narrZ: ")`가 개행 문자로 시작하므로 결과 앞에 빈 줄이 하나 생기고, 각 원소를 `%3d` 뒤에 공백 두 칸을 붙여 출력하므로 실행 예시보다 간격이 넓으며 줄 끝에 공백이 남는다. 또 마지막에 개행 문자를 출력하지 않으므로, 터미널에서 실행하면 다음 셸 프롬프트가 같은 줄에 이어서 나타난다.

> **참고:** 크기를 함께 받을 수 있다면 `void arrSumN(const int *pX, const int *pY, int *pZ, int n)`처럼 입력 배열을 `const`로 받고, 함수 안에서 `*(pZ + i) = *(pX + i) + *(pY + i);`를 `n`번 반복하여 배열 전체를 한 번의 호출로 처리할 수 있다([8장 3.4절](../../Lecture-Notes/Ch08_Pointers/Concepts_Lecture.ko.md#34-함수에-배열-전달)).

## 3. 세 수 정렬

### 3.1 문제

과제의 세 번째 문항은 포인터와 관련한 문제를 자유롭게 내고 푸는 자유 문항이며, 이 절의 문제는 그 형식에 맞춰 새로 낸 것이다.

사용자로부터 정수 3개를 입력받아 세 변수에 저장한 뒤, 포인터를 사용해 세 변수의 값을 오름차순으로 정렬하여 출력하는 프로그램을 작성하라.

**프로그램 요구사항:**

1. 두 변수의 값을 맞바꾸는 `swap()` 함수(1절)와, 세 변수의 주소를 받아 그 값을 오름차순으로 정렬하는 `void sort3(int* pa, int* pb, int* pc)` 함수를 정의하여 사용한다.
2. 정렬 결과는 `main()`의 변수 `x`, `y`, `z`에 그대로 반영되어야 한다.

**실행 예시:**

```text
정수 3개 입력: 9 -2 5
정렬 전: x = 9, y = -2, z = 5
정렬 후: x = -2, y = 5, z = 9

Program ended with exit code: 0
```

### 3.2 풀이

**접근 방법:** 이웃한 두 값을 비교하여 앞의 값이 더 크면 교환하는 단계를 세 번 거친다. 교환에는 1절의 `swap()`을 그대로 다시 쓴다.

- **1단계와 2단계:** `*pa > *pb`이면 `*pa`와 `*pb`를, 이어서 `*pb > *pc`이면 `*pb`와 `*pc`를 교환한다. 두 단계를 거치면 세 값 중 가장 큰 값이 `*pc`로 옮겨진다.
- **3단계:** 남은 두 값 `*pa`와 `*pb`를 한 번 더 비교하여 교환하면 세 값이 오름차순이 된다.
- **주소의 재전달:** `sort3()`의 매개변수 `pa`, `pb`, `pc`에는 이미 `main()`의 `x`, `y`, `z`의 주소가 들어 있으므로, `swap()`을 호출할 때 `swap(pa, pb)`처럼 그대로 넘긴다. `swap()`은 받은 주소를 역참조하여 값을 바꾸므로, 함수 호출을 두 단계 거쳐도 `main()`의 변수가 직접 바뀐다([8장 3.2절](../../Lecture-Notes/Ch08_Pointers/Concepts_Lecture.ko.md#32-포인터를-통한-변수-수정)).

입력이 `9 -2 5`이면 `x`, `y`, `z`는 처음에 각각 9, -2, 5이고, 각 단계 뒤의 값은 다음과 같다.

| 단계 | 비교 | 교환 | `x` | `y` | `z` |
|:-----|:-----|:-----|:-----|:-----|:-----|
| 1단계 | `*pa > *pb`, 곧 9 > -2는 참 | `swap(pa, pb)` | -2 | 9 | 5 |
| 2단계 | `*pb > *pc`, 곧 9 > 5는 참 | `swap(pb, pc)` | -2 | 5 | 9 |
| 3단계 | `*pa > *pb`, 곧 -2 > 5는 거짓 | 없음 | -2 | 5 | 9 |

*표 1. `9 -2 5`를 입력했을 때 `sort3()`의 단계별 변수 값*

**코드:** [Solution/Q3.c](Solution/Q3.c)

```c
/**
 * @file    Q3.c
 * @brief   Q3. 세 수 정렬
 * @author  박철원 (Cheolwon Park)
 * @date    2026-10-19
 */

#include <stdio.h>

void swap(int* a, int* b)
{
	int tmp = *a;
	*a = *b;
	*b = tmp;
}

void sort3(int* pa, int* pb, int* pc)
{
	if (*pa > *pb)
		swap(pa, pb);
	if (*pb > *pc)
		swap(pb, pc);
	if (*pa > *pb)
		swap(pa, pb);
}

int main()
{
	int x, y, z;

	printf("정수 3개 입력: ");
	scanf(" %d %d %d", &x, &y, &z);

	printf("정렬 전: x = %d, y = %d, z = %d\n", x, y, z);
	sort3(&x, &y, &z);
	printf("정렬 후: x = %d, y = %d, z = %d\n", x, y, z);
}
```

### 3.3 실행 결과

`gcc -std=c99 -Wall`로 경고 없이 컴파일되며, 실행 예시와 같은 값을 입력한 결과는 다음과 같다.

```text
정수 3개 입력: 9 -2 5
정렬 전: x = 9, y = -2, z = 5
정렬 후: x = -2, y = 5, z = 9
```

실행 예시와 같다. 1, 2, 3을 여섯 가지 순서로 모두 입력해도 결과는 `x = 1, y = 2, z = 3`이고, 같은 값이 섞인 `5 5 1`은 `x = 1, y = 5, z = 5`가 된다. 비교는 입력과 관계없이 항상 세 번이며, 교환이 가장 많이 일어나는 입력은 내림차순인 `3 2 1`로 세 단계 모두에서 교환한다.

```text
정수 3개 입력: 3 2 1
정렬 전: x = 3, y = 2, z = 1
정렬 후: x = 1, y = 2, z = 3
```

> **주의:** `sort3()` 안에서 `swap(&pa, &pb);`처럼 `&`를 붙이면 `pa`의 값(`x`의 주소)이 아니라 포인터 변수 `pa` 자신의 주소, 곧 `int**`형 값이 전달된다. 매개변수형 `int*`와 맞지 않으므로 clang은 `-Wincompatible-pointer-types` 경고를 내고, gcc 16은 같은 이름의 오류로 컴파일을 멈춘다. 경고를 무시하고 clang으로 만든 실행 파일에 `9 -2 5`를 입력하면 `x = 5, y = -2, z = 9`처럼 정렬되지 않은 결과가 나온다.

|:----|:---------|
| 포인터를 이용한 교환 | `swap(int* a, int* b)`가 두 변수의 주소를 받아 `*a`와 `*b`를 임시 변수로 교환하면 호출한 쪽의 변수가 바뀐다. |
| 임시 변수의 필요성 | `*a = *b;`를 먼저 실행하면 원래 `*a`의 값이 사라지므로, 교환 전에 한쪽 값을 임시 변수에 저장해야 한다. |
| 원소 주소의 전달 | `&arrX[i]`는 `arrX + i`와 같은 주소이며, 원소의 주소를 넘기면 함수가 그 원소를 읽거나 바꿀 수 있다. |
| 출력 매개변수 | `arrSum()`의 `pZ`처럼 함수가 결과를 기록하는 포인터 매개변수를 출력 매개변수라 한다. |
| 정해진 원형과 역할 분담 | 크기 매개변수가 없는 원형에서는 함수가 원소 하나를 처리하고 호출한 쪽이 반복하는 편이 배열 크기에 묶이지 않는다. |
| 출력 형식의 차이 | 계산 결과가 같아도 개행 문자와 형식 지정자의 폭에 따라 빈 줄, 간격, 줄 끝 공백이 실행 예시와 달라질 수 있다. |
| 주소의 재전달 | 포인터 매개변수는 이미 주소를 담고 있으므로 다른 함수에 넘길 때 `swap(pa, pb)`처럼 그대로 전달하며, `&pa`는 포인터 변수 자신의 주소인 `int**`형 값이 된다. |
| 세 값의 정렬 | 이웃한 두 값을 비교하여 교환하는 단계를 세 번 거치면 세 값이 오름차순이 된다. |

## 점검 문제

1. **포인터 자체의 교환:** `void swap2(int *a, int *b) { int *t = a; a = b; b = t; }`를 `swap2(&x, &y);`로 호출하면 `x`, `y`의 값은 바뀌는가? 이유를 쓰라.

   <details>
   <summary>정답</summary>

   바뀌지 않는다. `a`와 `b`는 `&x`, `&y`를 복사받은 `swap2()`의 지역 변수이므로, 두 포인터의 값(주소)을 서로 바꿔도 `main()`의 `x`, `y`에는 영향이 없다. 원본을 바꾸려면 `*a`와 `*b`, 즉 가리키는 값을 교환해야 한다.

   </details>

2. **원소 단위 호출:** 2절의 배열에서 `arrSum(&arrX[3], &arrY[3], &arrZ[3]);`만 호출하고 나머지 원소는 호출하지 않았다면 `arrZ`의 내용은 무엇인가?

   <details>
   <summary>정답</summary>

   `arrZ`는 `{ 0 }`으로 초기화되어 모든 원소가 0이므로, 호출 뒤에는 `arrZ[3]`만 -32 + 6 = -26으로 바뀌어 `{0, 0, 0, -26}`이 된다.

   </details>

3. **배열 전체 처리:** `void arrSum(int* pX, int* pY, int* pZ)`의 원형을 바꾸지 않고 함수 한 번의 호출로 배열 전체를 처리하게 만들 때의 문제점을 쓰라.

   <details>
   <summary>정답</summary>

   함수 안에서 포인터만으로는 배열의 원소 개수를 알 수 없으므로(`sizeof(pX)`는 포인터 크기이다), 크기를 4처럼 함수 안에 고정해야 한다. 그러면 길이가 다른 배열에는 쓸 수 없고, 더 짧은 배열을 넘기면 배열 범위를 넘어 접근하게 된다. 그래서 원형을 바꿀 수 없을 때는 원소 하나를 처리하게 하고 호출한 쪽에서 반복하는 편이 안전하다.

   </details>

4. **교환 과정 추적:** 3절의 프로그램에 `3 2 1`을 입력하면 `sort3()`의 각 단계 뒤에 `x`, `y`, `z`의 값은 어떻게 되는가?

   <details>
   <summary>정답</summary>

   1단계에서 3 > 2가 참이므로 교환하여 (2, 3, 1), 2단계에서 3 > 1이 참이므로 교환하여 (2, 1, 3), 3단계에서 2 > 1이 참이므로 교환하여 (1, 2, 3)이 된다. 세 단계 모두에서 교환이 일어나며, 이 입력이 교환이 가장 많이 일어나는 경우이다.

   </details>

5. **내림차순 정렬:** `sort3()`이 세 값을 내림차순으로 정렬하게 하려면 무엇을 바꾸어야 하는가?

   <details>
   <summary>정답</summary>

   세 비교의 `>`를 모두 `<`로 바꾼다. 그러면 1단계와 2단계를 거쳐 가장 작은 값이 `*pc`로 옮겨지고, 3단계에서 남은 두 값이 큰 값부터 놓인다. 예를 들어 `9 -2 5`를 입력하면 `x = 9, y = 5, z = -2`가 된다.

   </details>
