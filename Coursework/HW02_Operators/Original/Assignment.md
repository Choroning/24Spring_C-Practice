This is the second assignment of section 3 of Computer Language and Training Ⅰ. It consists of two exercises from Chapter 3 of the textbook and one problem of writing free code.

- **Contents:** For a coding problem, an analysis of the code must be written together with the code.
- **Sample Runs:** The line `Program ended with exit code: 0` at the end of a sample run is not output of the program but a termination message that the Xcode console appends.

## Problem 1. Printing a Value in Different Bases

**Textbook Problem:** Chapter 3 exercise 7

Referring to the sample run, read an arbitrary positive integer from the user into the variable `no`, and print that value in decimal, octal, and hexadecimal form.

**Sample Run:**

```text
enter no: 10
10, 012, 0xa

Program ended with exit code: 0
```

## Problem 2. Basic Arithmetic

**Textbook Problem:** Chapter 3 exercise 9

Referring to the sample run, read three integers from the user and compute and print their sum and average. The average must be a floating-point value.

**Sample Run:**

```text
Enter 3 values: 1 2 4
     1
     2
     4
--------
     7
   2.3

Program ended with exit code: 0
```
