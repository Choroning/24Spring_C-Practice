# HW2 과제 안내문 — 연산자

[레포지토리 안내](../../../README.ko.md) | [English](Assignment.md) | [한국어](Assignment.ko.md)

> **최종 수정일:** 2026-11-24

컴퓨터언어실습Ⅰ 3분반의 2차 과제이다. 교재 3장의 연습 문제 두 개와 자유 코드를 작성하는 문제 하나로 이루어진다.

- **작성 내용:** 코드 작성 문제는 코드와 함께 반드시 코드 분석 내용을 작성해야 한다.
- **실행 예시:** 실행 예시 끝의 `Program ended with exit code: 0`은 프로그램의 출력이 아니라 Xcode 콘솔이 덧붙이는 종료 메시지이다.

---

<br>

## 문제 1. 값의 n진수 출력

**교재 문항:** 3장 연습 문제 7번

실행 예시를 참고하여 변수 `no`에 사용자로부터 임의의 양의 정수값을 입력받은 후 해당 값을 10진수, 8진수, 16진수 형태로 출력하라.

**실행 예시:**

```text
enter no: 10
10, 012, 0xa

Program ended with exit code: 0
```

---

<br>

## 문제 2. 연산의 기본

**교재 문항:** 3장 연습 문제 9번

실행 예시를 참고하여 정수 3개를 사용자로부터 입력받은 후, 합과 평균을 계산하여 출력하라. 평균은 실수값으로 나와야 한다.

**실행 예시:**

```text
Enter 3 values: 1 2 4
     1
     2
     4
--------
     7
   2.3

Program ended with exit code: 0
```

## 문제 3. 자유 코드

지금까지 학습한 내용을 활용해 자유롭게 코드를 작성하고, 왜 해당 코드를 작성했는지 설명하라. 강의 내용을 얼마나 이해했는지 스스로 정리하는 것이 목적이다.
