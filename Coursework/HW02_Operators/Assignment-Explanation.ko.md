## 2. 문제 1: 값의 n진수 출력

### 2.1 문제

**교재 문항:** 3장 연습 문제 7번

실행 예시를 참고하여 변수 `no`에 사용자로부터 임의의 양의 정수값을 입력받은 후 해당 값을 10진수, 8진수, 16진수 형태로 출력하라.

**실행 예시:**

```text
enter no: 10
10, 012, 0xa

Program ended with exit code: 0
```

### 2.2 풀이

**접근 방법:** 값은 하나만 저장하고, 진법은 출력할 때 `printf`의 변환 지정자로 고른다. 정수는 메모리에 2진수로 저장될 뿐이며 10진수, 8진수, 16진수는 그 값을 글자로 나타내는 방법의 차이이기 때문이다.

- **변환 지정자:** `%d`는 10진수, `%o`는 8진수, `%x`는 소문자 16진수로 출력한다.
- **`#` 플래그:** `%#o`는 8진수 앞에 `0`을, `%#x`는 16진수 앞에 `0x`를 붙인다. 이 접두사는 C 소스 코드에서 8진수와 16진수 정수 상수를 쓰는 표기(`012`, `0xa`)와 같다.
- **인자:** 세 변환이 모두 같은 변수를 출력하므로 `no`를 세 번 넘긴다.

**코드:** [Solution/Q1.c](Solution/Q1.c)

```c
/**
 * @file    A10303-1_C04Q1.c
 * @brief   Q1. 값의 n진수 출력
 * @author  박철원 (Cheolwon Park)
 * @date    2024-03-20
 * 
 * @note    소스 코드에 사용된 scanf_s는 Visual Studio 이외의
 *	    IDE에서 실행이 불가할 수 있음에 주의하시기 바랍니다.
 */

#include <stdio.h>

int main()
{
	int no;
	printf("enter no: ");
	scanf_s(" %d", &no);
	printf("%d, %#o, %#x", no, no, no);
}
```

### 2.3 실행 결과와 경계 조건

**실행 결과:** 실행 예시와 같다. 10은 8진수로 1 × 8 + 2 = `012`, 16진수로 `0xa`이다. 출력 끝에 줄바꿈을 출력하지 않는다.

```text
enter no: 10
10, 012, 0xa
enter no: 255
255, 0377, 0xff
```

> **주의:** **0과 음수.** `#` 플래그는 값이 0이면 `0x` 접두사를 붙이지 않으므로 0은 `0, 0, 0`으로 출력된다. 또 `%o`와 `%x`는 `unsigned int` 인자를 기대하므로, 문제의 가정과 달리 음수를 입력하면 그 비트 패턴을 부호 없는 수로 해석한 값이 출력된다. 32비트 `int`에서 -10은 $2^{32} - 10$으로 해석되어 `037777777766`, `0xfffffff6`이 된다.

```text
enter no: 0
0, 0, 0
enter no: -10
-10, 037777777766, 0xfffffff6
```

## 3. 문제 2: 연산의 기본

### 3.1 문제

**교재 문항:** 3장 연습 문제 9번

실행 예시를 참고하여 정수 3개를 사용자로부터 입력받은 후, 합과 평균을 계산하여 출력하라. 평균은 실수값으로 나와야 한다.

**실행 예시:**

```text
Enter 3 values: 1 2 4
     1
     2
     4
--------
     7
   2.3

Program ended with exit code: 0
```

### 3.2 풀이

**접근 방법:** 합은 정수로 계산하고, 평균은 실수 나눗셈으로 구하며, 모든 수를 폭 6의 오른쪽 정렬로 출력하여 일의 자리를 맞춘다.

- **합:** `sum = first + second + third;`로 정수 합을 구한다.
- **평균:** `sum / 3.0`은 실수 리터럴 `3.0` 때문에 `sum`이 `double`로 변환되어 실수 나눗셈이 된다. `sum / 3`으로 쓰면 7 / 3 = 2의 정수 나눗셈이 되어 소수 부분을 잃는다.
- **정렬:** `%6d`는 정수를 최소 6칸에 오른쪽 정렬로 출력하고, `%6.1lf`는 소수점 아래 1자리까지 반올림한 실수를 최소 6칸에 출력한다. 2.333...은 `2.3`이 되어 앞에 공백 3칸이 붙는다.

**코드:** [Solution/Q2.c](Solution/Q2.c)

```c
/**
 * @file    A10303-1_C04Q2.c
 * @brief   Q2. 연산의 기본
 * @author  박철원 (Cheolwon Park)
 * @date    2024-03-23
 * 
 * @note    소스 코드에 사용된 scanf_s는 Visual Studio 이외의
 *	    IDE에서 실행이 불가할 수 있음에 주의하시기 바랍니다.
 */

#include <stdio.h>

int main()
{
	int first, second, third, sum;
	printf("Enter 3 values: ");
	scanf_s(" %d %d %d", &first, &second, &third);
	sum = first + second + third;
	printf("%6d \n", first);
	printf("%6d \n", second);
	printf("%6d \n", third);
	printf("-------- \n");
	printf("%6d \n", sum);
	printf("%6.1lf \n", sum / 3.0);
}
```

### 3.3 실행 결과와 경계 조건

**실행 결과:** 실행 예시와 같다. 다만 각 형식 문자열이 `" \n"`으로 끝나므로 모든 줄 끝에 공백이 하나 남는다.

```text
Enter 3 values: 1 2 4
     1 
     2 
     4 
-------- 
     7 
   2.3 
```

> **참고:** 필드 폭은 최소 너비이므로, 출력할 글자 수가 6을 넘으면 잘리지 않고 그대로 출력되어 정렬이 어긋난다. 평균이 `33334.7`처럼 7글자이면 다른 줄보다 한 칸 길어진다.

```text
Enter 3 values: 100000 -3 7
100000 
    -3 
     7 
-------- 
100004 
33334.7 
```

## 4. 문제 3: 자유 코드

### 4.1 문제

지금까지 학습한 내용을 활용해 자유롭게 코드를 작성하고, 왜 해당 코드를 작성했는지 설명하라. 강의 내용을 얼마나 이해했는지 스스로 정리하는 것이 목적이다.

### 4.2 풀이

**작성 의도:** 예비 카페 창업자가 메뉴 가격과 예상 판매량을 넣으면 메뉴판, 매출 전표, 목표 매출과의 차이를 보여 주는 매출 계산 프로그램을 작성하였다. 이 과제까지 배운 변수 선언, `scanf`를 이용한 입력, 산술 연산, `printf`의 필드 폭 지정, 정수와 실수 나눗셈의 구분을 한 프로그램에서 모두 쓰도록 주제를 골랐다.

- **변수 설계:** 음료 3종(아메리카노, 바닐라 라떼, 한라봉 에이드)과 빵 3종(블루베리 베이글, 딸기 케이크, 치킨 샌드위치)의 가격과 판매 개수를 각각 `int` 변수에 저장하고, 음료와 빵의 총매출, 총판매 개수, 목표 매출을 별도 변수로 둔다. 변수 이름은 메뉴 이름의 약자(`amer`, `vala`, `hala`, `blba`, `stca`, `chsa`)이다.
- **입력 단계:** 목표 매출, 메뉴별 가격 6개, 메뉴별 판매 개수 6개를 차례로 입력받는다. 가격을 입력받은 뒤에는 `%5d`로 가격을 정렬한 메뉴판을 출력한다.
- **계산 단계:** 메뉴별 매출은 가격 × 개수이고, 음료와 빵 각각의 총매출과 총판매 개수는 세 메뉴의 합이다.
- **출력 단계:** 메뉴별로 `가격 * 개수 => 매출`을 `%5d`, `%4d`, `%8d`로 정렬하여 출력하고, 메뉴당 평균 판매 개수와 평균 매출은 `/ 3.0`으로 실수 나눗셈을 하여 `%.1lf`로 출력한다. 마지막으로 전체 판매 개수와 총매출, 목표 매출에서 총매출을 뺀 차이를 출력한다.

 * 
 * @note    소스 코드에 사용된 scanf_s는 Visual Studio 이외의
 *	    IDE에서 실행이 불가할 수 있음에 주의하시기 바랍니다.

	int blba_amount, stca_amount, chsa_amount;     // 빵 항목들의 개수
	int bread, bread_amount;     // 순서대로 빵 항목들의 총 매출, 총 판매개수

	int target;     // 목표 매출

	printf("안녕하세요. 예비 카페 창업주들을 위한 매출 계산 프로그램입니다. \n");
	printf("매출 예상에 쓰일 메뉴는 총 6개이며, 음료 3개와 빵 3개입니다. \n\n");
	printf(" [ 음료 메뉴판 ]                [ 빵 메뉴판 ] \n");
	printf(" 아메리카노                     블루베리 베이글 \n");

	printf("\n치킨 샌드위치는 몇 개를 판매할까요? (양의 정수만 입력, 최대 9,999개) \n");
	scanf_s(" %d", &chsa_amount);

	drink_amount = amer_amount + vala_amount + hala_amount;
	drink = amer * amer_amount + vala * vala_amount + hala * hala_amount;

	bread_amount = blba_amount + stca_amount + chsa_amount;
	bread = blba * blba_amount + stca * stca_amount + chsa * chsa_amount;

	printf("\n\n\n\n설정하신 가격을 바탕으로 매출전표를 완성했습니다. \n\n");
	printf("======================= * ======================= \n");
	printf("[ 음료 매출 ] \n\n");
	printf("아메리카노       %5d원 * %4d잔 => %8d원 \n", amer, amer_amount, amer * amer_amount);
	printf("바닐라 라떼      %5d원 * %4d잔 => %8d원 \n", vala, vala_amount, vala * vala_amount);
	printf("한라봉 에이드    %5d원 * %4d잔 => %8d원 \n\n", hala, hala_amount, hala * hala_amount);
	printf("음료는 총 %d잔을 판매하였고, 한 메뉴당 평균 판매 잔수는 %.1lf잔입니다. \n", drink_amount, drink_amount / 3.0);
	printf("음료 매출은 총 %d원이고, 메뉴당 평균 매출은 약 %.1lf원입니다. \n\n", drink, drink / 3.0);

	printf("[ 빵 매출 ] \n\n");
	printf("블루베리 베이글  %5d원 * %4d개 => %8d원 \n", blba, blba_amount, blba * blba_amount);
	printf("딸기 케이크      %5d원 * %4d개 => %8d원 \n", stca, stca_amount, stca * stca_amount);
	printf("치킨 샌드위치    %5d원 * %4d개 => %8d원 \n\n", chsa, chsa_amount, chsa * chsa_amount);
	printf("빵은 총 %d개를 판매하였고, 한 메뉴당 평균 판매 개수는 %.1lf개입니다. \n", bread_amount, bread_amount / 3.0);
	printf("빵 매출은 총 %d원이고, 메뉴당 평균 매출은 약 %.1lf원입니다. \n\n", bread, bread / 3.0);

	printf("음료와 빵은 총 %d개를 판매하였고, 총 매출은 %d원입니다. \n", drink_amount + bread_amount, drink + bread);
	printf("======================= * ======================= \n\n");

	printf("목표 매출과 %9d원 만큼 차이납니다. \n", target - (drink + bread));
}

## 요약

| 개념 | 핵심 요약 |
|:-----|:-----|
| 진법별 출력 | `%d`, `%o`, `%x`는 같은 정수를 10진수, 8진수, 16진수 글자로 출력한다. |
| `#` 플래그 | `%#o`는 `0`, `%#x`는 `0x` 접두사를 붙이지만, 값이 0이면 `0x`를 붙이지 않는다. |
| 부호 없는 해석 | `%o`와 `%x`는 인자를 `unsigned int`로 해석하므로 음수는 큰 양수로 출력된다. |
| 필드 폭 | `%6d`는 최소 6칸에 오른쪽 정렬하며, 값이 더 길면 잘리지 않고 정렬이 어긋난다. |
| 정밀도 | `%6.1lf`는 소수점 아래 1자리로 반올림한 실수를 최소 6칸에 출력한다. |
| 실수 평균 | `sum / 3.0`처럼 실수 리터럴로 나누어야 정수 나눗셈으로 소수 부분을 잃지 않는다. |
| 자유 코드 설계 | 입력, 계산, 출력 단계로 나누어 변수, 산술 연산, 형식화된 출력을 한 프로그램에 조합한다. |
| 정수 오버플로 | 곱과 합이 32비트 `int`의 최댓값 2,147,483,647을 넘을 수 있으면 더 넓은 타입을 쓴다. |

## 점검 문제

1. **진법 출력:** `printf("%d, %#o, %#x", 255, 255, 255);`의 출력을 쓰라.

   <details>
   <summary>정답</summary>

   `255, 0377, 0xff`이다. 255 = 3 × 64 + 7 × 8 + 7이므로 8진수로 377이고, 255 = 15 × 16 + 15이므로 16진수로 ff이다. `#` 플래그가 각각 `0`과 `0x`를 붙인다.

   </details>

2. **평균의 계산:** `int sum = 7;`일 때 `printf("%6.1lf", sum / 3);`의 문제점은 무엇이며 어떻게 고쳐야 하는가?

   <details>
   <summary>정답</summary>

   `sum / 3`은 정수 나눗셈이므로 결과가 `int` 2이다. `%lf`는 `double` 인자를 기대하는데 `int`를 넘기면 형식과 인자의 타입이 맞지 않아 정의되지 않은 동작이 되고, 타입이 맞더라도 소수 부분은 이미 사라졌다. `sum / 3.0`으로 쓰면 실수 나눗셈이 되어 `   2.3`이 출력된다.

   </details>

3. **필드 폭:** `printf("[%6d]", 42);`와 `printf("[%6d]", 1234567);`의 출력을 쓰라.

   <details>
   <summary>정답</summary>

   `[    42]`와 `[1234567]`이다. 42는 2글자이므로 앞에 공백 4칸이 붙어 6칸이 된다. 필드 폭은 최소 너비이므로 7글자인 1234567은 잘리지 않고 그대로 출력된다.

   </details>

4. **오버플로:** 문제 3의 프로그램에서 음료 세 메뉴의 가격을 모두 80,000원, 판매 개수를 모두 9,000잔으로 입력하면 음료 총매출 `drink`의 계산에 어떤 문제가 생기는가?

   <details>
   <summary>정답</summary>

   메뉴 하나의 매출은 80,000 × 9,000 = 720,000,000원으로 `int`에 들어가지만, 세 메뉴의 합 2,160,000,000원은 32비트 `int`의 최댓값 2,147,483,647보다 크다. 부호 있는 정수의 오버플로는 정의되지 않은 동작이며, 일반적인 환경에서는 음수 같은 잘못된 값이 출력된다. `drink`를 `long long`으로 선언하고 곱셈도 `long long`으로 계산해야 한다.

   </details>
