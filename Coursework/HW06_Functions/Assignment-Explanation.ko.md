## 2. 문제 1: 합 구하기

### 2.1 요구사항

사용자로부터 임의의 정수를 입력받은 뒤, 실행 예시를 참고하여 `getSum()` 함수를 통해 0부터 입력받은 정수까지의 합을 구해 출력하라.

**실행 예시:**

```text
>> Enter value: 4
-> Sum(4) ---> 10

Program ended with exit code: 0
```

```text
>> Enter value: -3
-> Sum(-3) ---> -6

Program ended with exit code: 0
```

두 번째 실행 예시에서 알 수 있듯이 입력이 음수이면 0부터 그 수까지 내려가며 더한다. -3이면 0 + (-1) + (-2) + (-3) = -6이다.

### 2.2 해결 방법

`getSum()`은 매개변수 `val`의 부호에 따라 세 경우로 나누어 합을 구한다.

| `val`의 범위 | 처리 | 예 |
|:-----|:-----|:-----|
| `val > 0` | `i`를 1부터 `val`까지 늘리며 더한다 | `getSum(4)` = 1 + 2 + 3 + 4 = 10 |
| `val == 0` | 바로 0을 반환한다 | `getSum(0)` = 0 |
| `val < 0` | `i`를 -1부터 `val`까지 줄이며 더한다 | `getSum(-3)` = (-1) + (-2) + (-3) = -6 |

*표 1. `val`의 부호에 따른 `getSum()`의 처리*

0을 더해도 합은 바뀌지 않으므로 두 반복문은 0이 아니라 1과 -1에서 시작한다. `sum`은 0으로 초기화한 지역 변수이며, 각 경우의 끝에서 `return sum;`으로 결과를 돌려준다. `main()`은 입력받은 값을 `getSum()`에 인수로 넘기고, 반환값을 `printf`의 인수로 바로 사용하여 `-> Sum(%d) ---> %d` 형식으로 출력한다.

반복문 없이 등차수열의 합 공식으로도 같은 값을 구할 수 있다. $n \ge 0$이면 $\frac{n(n+1)}{2}$, $n < 0$이면 $\frac{n(1-n)}{2}$이다.

### 2.3 코드와 실행 결과

**코드:** [Solution/Q1.c](Solution/Q1.c)

```c
/**
 * @file    A10303-1_C06Q1.c
 * @brief   Q1. 합 구하기
 * @author  박철원 (Cheolwon Park)
 * @date    2024-05-01
 */

#include <stdio.h>
int getSum(int val);

int main()
{
	int val;

	printf(">> Enter value: ");
	scanf(" %d", &val);

	printf("-> Sum(%d) ---> %d", val, getSum(val));
}

int getSum(int val) {
	int i, sum = 0;

	if (val > 0) {
		for (i = 1; i <= val; i++) {
			sum += i;
		}
		return sum;
	}
	else if (val == 0) {
		return 0;
	}
	else {
		for (i = -1; i >= val; i--) {
			sum += i;
		}
		return sum;
	}
}
```

**실행 결과:** 두 실행 예시와 같은 값을 입력하면 같은 결과가 나온다. 결과를 출력한 뒤 줄을 바꾸지 않으므로 터미널에서는 다음 셸 프롬프트가 같은 줄에 이어진다.

```text
>> Enter value: 4
-> Sum(4) ---> 10
```

```text
>> Enter value: -3
-> Sum(-3) ---> -6
```

### 2.4 경계 경우

- **0과 1:** 0을 입력하면 `val == 0` 분기에서 0을, 1을 입력하면 반복문이 한 번 실행되어 1을 출력한다.
- **오버플로:** 32비트 `int`의 최댓값은 2,147,483,647이다. 65535까지의 합은 $\frac{65535 \times 65536}{2}$ = 2,147,450,880으로 범위 안이지만, 65536까지의 합 2,147,516,416은 범위를 넘으므로 `sum += i`에서 부호 있는 정수 오버플로(정의되지 않은 동작)가 일어난다. 음수도 마찬가지로 -65535까지만 올바른 합을 구한다.
- **잘못된 입력:** 숫자가 아닌 문자를 입력하면 `scanf`가 실패하여 `val`에 값이 저장되지 않으므로, 초기화하지 않은 `val`을 읽는 정의되지 않은 동작이 된다. `scanf`의 반환값이 1인지 검사하면 이를 막을 수 있다.

## 3. 문제 2: 조건에 따라 합 구하기

### 3.1 요구사항

사용자로부터 10개의 임의의 정수를 순차적으로 입력받은 뒤, 실행 예시를 참고하여 `getSign()` 함수를 통해 입력받은 정수의 양수, 음수 여부를 확인하고 양수인 경우에만 합산하여 합을 구해 출력하라.

**실행 예시:**

```text
>> (1) Input value: 3
>> (2) Input value: -1
>> (3) Input value: 2
>> (4) Input value: -4
>> (5) Input value: 1
>> (6) Input value: 2
>> (7) Input value: -5
>> (8) Input value: -23
>> (9) Input value: 5
>> (10) Input value: 6
-> Sum of positive values: 19

Program ended with exit code: 0
```

실행 예시의 양수는 3, 2, 1, 2, 5, 6이고 그 합은 19이다.

### 3.2 해결 방법

`getSign()`은 매개변수 `tmp`가 0보다 크면 1을, 그렇지 않으면 0을 반환한다. `main()`은 `i`를 1부터 10까지 늘리며 `>> (i) Input value: ` 프롬프트를 출력하고 정수를 읽은 뒤, `if (getSign(val))`이 참일 때만 `sum`에 더한다. C의 조건식은 0이 아니면 참이므로 `getSign()`의 반환값을 비교 연산 없이 그대로 조건으로 쓸 수 있다.

입력값은 반복할 때마다 같은 변수 `val`에 덮어쓰므로 10개의 값을 모두 저장할 필요가 없고, 합에 필요한 `sum`만 반복문 밖에서 0으로 초기화해 둔다.

### 3.3 코드와 실행 결과

**코드:** [Solution/Q2.c](Solution/Q2.c)

```c
/**
 * @file    A10303-1_C06Q2.c
 * @brief   Q2. 조건에 따라 합 구하기
 * @author  박철원 (Cheolwon Park)
 * @date    2024-05-01
 */

#include <stdio.h>
int getSign(int tmp);

int main()
{
	int val, i, sum = 0;

	for (i = 1; i <= 10; i++) {
		printf(">> (%d) Input value: ", i);
		scanf(" %d", &val);
		
		if (getSign(val)) {
			sum += val;
		}
	}
	printf("-> Sum of positive values: %d", sum);
}

int getSign(int tmp) 
{
	if (tmp > 0) {
		return 1;
	}
	else {
		return 0;
	}
}
```

**실행 결과:** 실행 예시와 같은 10개의 값을 입력하면 같은 합 19가 출력된다.

```text
>> (1) Input value: 3
>> (2) Input value: -1
>> (3) Input value: 2
>> (4) Input value: -4
>> (5) Input value: 1
>> (6) Input value: 2
>> (7) Input value: -5
>> (8) Input value: -23
>> (9) Input value: 5
>> (10) Input value: 6
-> Sum of positive values: 19
```

### 3.4 경계 경우

- **0의 처리:** `getSign(0)`은 0을 반환하므로 0은 양수로 세지 않는다. 0을 더해도 합은 같으므로 조건을 `tmp >= 0`으로 바꾸어도 결과는 같다.
- **양수가 없는 입력:** 10개가 모두 0 이하이면 `sum`이 처음 값 0 그대로 남아 `-> Sum of positive values: 0`이 출력된다.
- **함수의 이름과 반환값:** `getSign()`은 이름과 달리 부호를 세 가지(-1, 0, 1)로 돌려주지 않고 양수인지 아닌지만 알려 주므로, 0과 음수를 구별해야 하는 문제에는 그대로 쓸 수 없다. 이 문제는 양수만 골라내면 되므로 1과 0만으로 충분하다.

## 점검 문제

1. **반환값:** 풀이의 `getSum()`에서 `getSum(-1)`, `getSum(0)`, `getSum(5)`의 반환값은 각각 얼마인가?

   <details>
   <summary>정답</summary>

   `getSum(-1)`은 `val < 0` 분기에서 -1 하나만 더하므로 -1, `getSum(0)`은 `val == 0` 분기에서 0, `getSum(5)`는 1 + 2 + 3 + 4 + 5 = 15이다.

   </details>

2. **함수 원형:** `Q1.c`에서 `int getSum(int val);` 줄을 지우면 어떻게 되는가?

   <details>
   <summary>정답</summary>

   `getSum()`의 정의가 `main()`보다 뒤에 있으므로 `main()`에서 호출하는 시점에 컴파일러는 그 함수를 알지 못한다. C99부터 암시적 선언은 표준에서 제거되었으므로 gcc 14 이상과 clang 16 이상은 오류를 내고, 그 이전 버전은 경고를 낸다. 정의를 `main()` 앞으로 옮기면 원형 없이도 컴파일된다.

   </details>

3. **오버플로:** 32비트 `int`에서 `getSum()`이 올바른 합을 돌려주는 가장 큰 양수 입력은?

   <details>
   <summary>정답</summary>

   65535이다. $\frac{65535 \times 65536}{2}$ = 2,147,450,880은 `int`의 최댓값 2,147,483,647보다 작지만, 65536을 입력하면 합이 2,147,516,416이 되어 범위를 넘는다.

   </details>

4. **조건의 변경:** `getSign()`의 조건을 `tmp >= 0`으로 바꾸면 문제 2의 출력이 달라지는가?

   <details>
   <summary>정답</summary>

   달라지지 않는다. 0도 더하게 되지만 0을 더해도 합이 바뀌지 않으므로, 어떤 입력에서도 출력되는 합은 같다.

   </details>

5. **합의 공식:** 반복문 없이 `getSum(-3)`의 값을 공식으로 구하라.

   <details>
   <summary>정답</summary>

   $n < 0$이면 $\frac{n(1-n)}{2}$이므로 $\frac{(-3)(1-(-3))}{2} = \frac{(-3) \times 4}{2} = -6$이다. 실행 예시의 결과와 같다.

   </details>
